01

集合：先把东西分好类

教材 1.1—1.3 · 建议 3 天 · 考试约 5—10 分

必拿分选择题常客
先说人话：集合就是一个“盒子”，把确定的东西放进去。你的书包是一个集合，里面的每本书是元素。盒子里不能放重复的书，书的顺序也不重要。

1. 四个符号，先分清

写法读作意思例子
a ∈ Aa 属于 Aa 是集合 A 里的元素2 ∈ {1,2,3}
A ⊆ BA 包含于 BA 里的每个元素都在 B 里{1,2} ⊆ {1,2,3}
A ⫋ BA 真包含于 BA ⊆ B 且 A ≠ B{1,2} ⫋ {1,2,3}
∅空集一个元素都没有的集合∅ ⊆ 任何集合

元素有三条性质：确定性（能不能明确判断）、互异性（不能重复）、无序性（不分先后）。考试最常用的是互异性，例如 {1, a} 中必须 a ≠ 1。

含 n 个元素的集合：子集 2n 个，真子集 2n−1 个，非空真子集 2n−2 个。

两个圆的重叠部分就是 A∩B；两个圆合起来是 A∪B。

空心圈表示不含端点，实心点表示含端点。区间写法：小括号不含，中括号含。

2. 三种运算，看“公共、合并、剩下”

运算符号怎么找一句口诀
交集A ∩ B两个集合都有的元素都要有
并集A ∪ B两个集合的全部元素（重复只写一次）有一个就行
补集∁UA全集 U 里去掉 A 剩下的元素剩下的
必背关系：A∩B ⊆ A ⊆ A∪B；A∩∁UA = ∅；A∪∁UA = U。求补集前，先看清全集 U 是什么。

阴影部分就是运算结果；求补集前，一定要先确定全集 U。

例 1　设 U = R，A = {x | −1 < x ≤ 3}，B = {x | x ≥ 2}。求 A∩B、A∪B、∁UA。

看解析（先自己画数轴）
画数轴：A 从 −1 到 3，左空右实；B 从 2 向右。 A∩B：两边都覆盖的部分是 [2, 3]。 A∪B：合起来是 (−1, +∞)。 ∁UA：U 里去掉 A，剩下 (−∞, −1] ∪ (3, +∞)。注意 −1 本来不在 A 里，所以补集里要包含它；3 在 A 里，所以补集里不包含它。

例 2　集合 A = {1, 2, 3} 有多少个子集？多少个真子集？

看解析
元素个数 n = 3，子集个数 2³ = 8 个。 真子集要去掉它自己，8 − 1 = 7 个。 8 个子集分别是：∅，{1}，{2}，{3}，{1,2}，{1,3}，{2,3}，{1,2,3}。
三个最容易丢分的点：
  • 忘了空集。题目说 A ⊆ B 求参数时，先问一句：A 能不能是 ∅？空集是任何集合的子集。
  • 端点开闭搞反。画数轴，空心不含、实心含；写区间时小括号不含、中括号含。
  • 描述法看错对象。{x | y = x²} 是 x 的范围 R；{y | y = x²} 是 y 的范围 [0, +∞)；{(x,y) | y = x²} 是图象上的点集。
自测（做完再看答案）
  1. A = {1,2,3}，B = {2,3,4}，求 A∩B 和 A∪B。
  2. 集合 {a, b} 有多少个子集？
  3. 把 {x | −2 ≤ x < 1} 写成区间。
对答案
1. A∩B = {2,3}；A∪B = {1,2,3,4}。 2. 2² = 4 个：∅，{a}，{b}，{a,b}。 3. [−2, 1)。左端含用中括号，右端不含用小括号。
文具分类就是集合：两个文具盒的交集，是两边都有的文具；并集，是两边合起来的全部文具。
02

逻辑用语：充分条件和必要条件

教材 1.4—1.5 · 建议 2 天 · 选择、填空约 5 分

必拿分易混
先说人话：“充分条件”就是“有它就够了”；“必要条件”就是“没它不行”。判断时只看箭头：p ⇒ q 表示“只要 p 成立，q 一定成立”。

1. 一张表分清“充分”和“必要”

关系读法谁充分谁必要
p ⇒ qp 推出 qp 是 q 的充分条件q 是 p 的必要条件
q ⇒ pq 推出 pq 是 p 的充分条件p 是 q 的必要条件
p ⇔ q互相推出p 与 q 互为充要条件
判断口诀：小范围推大范围。把 p、q 分别看成集合。如果 p 的范围更小、被包在 q 里面，那么 p 是 q 的充分条件，q 是 p 的必要条件。

小范围 ⇒ 大范围：x > 2 一定能推出 x > 1，但 x > 1 推不出 x > 2。

例 1　判断“x > 2”是“x > 1”的什么条件。

看解析
正方向：x > 2 ⇒ x > 1，成立。 反方向：x > 1 ⇒ x > 2，不成立。反例：x = 1.5。 所以“x > 2”是“x > 1”的充分不必要条件；“x > 1”是“x > 2”的必要不充分条件。

2. 全称量词与存在量词

∀：所有、任意
∃：存在、至少有一个

全称命题：∀x∈M，p(x) 对所有 x 都成立。

存在命题：∃x∈M，p(x) 至少有一个 x 成立。

¬(∀x∈M, p(x)) ⇔ ∃x∈M, ¬p(x)
¬(∃x∈M, p(x)) ⇔ ∀x∈M, ¬p(x)

否定口诀：换量词，否结论。∀ 变 ∃，∃ 变 ∀，再把后面的结论反过来。

例 2　写出“∀x ∈ R，x² ≥ 0”的否定。

看解析
∀ 换成 ∃；“≥”的否定是“<”。 答案：∃x ∈ R，x² < 0。 注意：不是“∀x ∈ R，x² < 0”，量词一定要换。
常见错误：
  • 把“充分”和“必要”说反。记住：箭头出发的一边是充分，箭头指向的一边是必要。
  • 否定时只换结论、忘了换量词；或者只换量词、忘了否定结论。
  • “>”的否定是“≤”，“<”的否定是“≥”；“且”的否定是“或”，“或”的否定是“且”。
自测
  1. “x = 1”是“x² = 1”的什么条件？
  2. “三角形是等边三角形”是“三角形是等腰三角形”的什么条件？
  3. 写出“∃x ∈ R，x + 1 < 0”的否定。
对答案
1. 充分不必要。x = 1 ⇒ x² = 1；但 x² = 1 还有 x = −1。 2. 充分不必要。等边一定是等腰，等腰不一定是等边。 3. ∀x ∈ R，x + 1 ≥ 0。
下雨是地湿的充分条件：下雨一定地湿；但地湿不一定是下雨，也可能是洒水车。身份证是进考场的必要条件：没它不行，但只有它也不够。
03

不等式：谁大谁小，怎么算

教材 2.1—2.2 · 建议 3 天 · 选择、填空、大题第(1)问

必拿分最值力争
先说人话：不等式就是“谁大谁小”。解不等式，就是找出让这句话成立的所有 x。它和等式的最大区别只有一条：两边乘或除以负数，不等号要反过来。

1. 不等式性质：能做什么，不能做什么

性质式子注意
两边同加a > b ⇒ a+c > b+c同加同减，方向不变
乘正数a > b，c > 0 ⇒ ac > bc方向不变
乘负数a > b，c < 0 ⇒ ac < bc方向要反过来
同向可加a > b，c > d ⇒ a+c > b+d只能加，不能减
同向可乘a > b > 0，c > d > 0 ⇒ ac > bd必须都是正数
注意：同向不等式不能相减、不能相除。例如 5 > 3、4 > 1，不能推出 5−4 > 3−1（1 > 2 是错的）。

2. 比较大小：作差法

作差→化简→判断符号→下结论
若 M − N > 0，则 M > N；若 M − N < 0，则 M < N；若 M − N = 0，则 M = N。

例 1　比较 (x+1)(x+3) 与 (x+2)² 的大小。

看解析
作差：(x+1)(x+3) − (x+2)² = (x²+4x+3) − (x²+4x+4) = −1。 差恒小于 0，所以 (x+1)(x+3) < (x+2)²，对任意 x 都成立。

3. 基本不等式：求最值的“万能钥匙”

a > 0，b > 0 时：(a+b)/2 ≥ √(ab)
当且仅当 a = b 时取等号。
变形：a+b ≥ 2√(ab)；ab ≤ ((a+b)/2)²
一正：a、b 都是正数→二定：和或积是定值→三相等：验证 a=b 能否取到

口诀：和定积最大，积定和最小。但“三相等”必须写出来，否则最值可能是取不到的。

半圆直径 AB 被 C 分成 a、b 两段。CD = √(ab)，半径 OD = (a+b)/2；垂线永远不超过半径。

例 2　已知 x > 0，求 x + 4/x 的最小值。

看解析
因为 x > 0，所以 x 和 4/x 都是正数，可以用基本不等式。 x + 4/x ≥ 2√(x · 4/x) = 2√4 = 4。 等号成立：x = 4/x，即 x² = 4，x = 2（负根舍去）。 所以当 x = 2 时，最小值是 4。

例 3　用 20 m 长的篱笆靠墙围一个矩形菜园（墙作为一边，不用篱笆），怎样围面积最大？

看解析（先画图）
设垂直于墙的两条边各为 x m，则平行于墙的边为 (20 − 2x) m，面积 S = x(20 − 2x)，其中 0 < x < 10。 S = 2x(10 − x)。把 x 与 10 − x 看成两个正数，它们的和是 10（定值）。 由 ab ≤ ((a+b)/2)²：x(10 − x) ≤ (10/2)² = 25，所以 S ≤ 2 × 25 = 50。 等号成立：x = 10 − x，即 x = 5。此时另一边为 10 m。 答：围成 5 m × 10 m 时面积最大，最大面积为 50 m²。
四个丢分点：
  • 没写“a、b 为正数”就直接用基本不等式。
  • 算出最值却不验证等号能否取到。等号取不到，那个“最值”就是假的。
  • 两边乘负数忘记变号。
  • 把“同向可加”误用成“同向可减”。
自测
  1. a > 0，b > 0，a + b = 6，求 ab 的最大值。
  2. 解不等式 2x − 3 > 5。
  3. 比较 a² + b² 与 2ab 的大小。
对答案
1. ab ≤ ((a+b)/2)² = 3² = 9，当 a = b = 3 时取到，最大值 9。 2. 2x > 8，所以 x > 4，解集 (4, +∞)。 3. a² + b² − 2ab = (a−b)² ≥ 0，所以 a² + b² ≥ 2ab，当 a = b 时取等号。

二次函数与一元二次不等式

教材 2.3 · 建议 4 天 · 考试约 10—15 分

必拿分大题常考
先说人话：二次函数是一条抛物线。它与 x 轴的交点，就是方程的根；抛物线在 x 轴上方或下方的部分，就是不等式的解。记住一句话：图在上方就是大于零，图在下方就是小于零。

1. 三个“二次”其实是一件事

名字写法看图象的哪里
二次函数y = ax² + bx + c（a ≠ 0）整条抛物线
一元二次方程ax² + bx + c = 0抛物线与 x 轴的交点
一元二次不等式ax² + bx + c > 0（或 < 0）抛物线在 x 轴上方的部分（或下方）
对称轴：x = −b/(2a)　顶点：(−b/(2a), (4ac−b²)/(4a))
判别式：Δ = b² − 4ac　Δ > 0 两个零点，Δ = 0 一个零点，Δ < 0 没有零点。

三种情况都按“开口向上”画。Δ 决定抛物线与 x 轴交几次，解集跟着图象走。

2. 解一元二次不等式：五步走

① 二次项系数化正→② 算 Δ→③ 求根→④ 画抛物线→⑤ 写解集
开口向上时的口诀：“大于取两边，小于取中间”。如果二次项系数是负数，先两边乘 −1，不等号要反过来，再套口诀。

绿色两块对应“大于取两边”，中间橙色一块对应“小于取中间”。解集就是横轴上对应的 x 范围。

例 1　解不等式 −x² + 2x + 3 ≥ 0。

看解析
两边乘 −1，不等号反向：x² − 2x − 3 ≤ 0。 因式分解：(x − 3)(x + 1) ≤ 0，根为 −1 和 3。 开口向上，小于等于零取两根之间：[−1, 3]。

例 2　解不等式 x² − 4x + 5 > 0。

看解析
Δ = (−4)² − 4×1×5 = 16 − 20 = −4 < 0。 开口向上且与 x 轴无交点，整条抛物线都在 x 轴上方。 所以对任意实数 x 都成立，解集是 R（全体实数）。 对比：如果是 x² − 4x + 5 < 0，那就无解，解集是 ∅。
常见错误：
  • 二次项系数是负数时，忘记变号就套“大于取两边”。
  • Δ < 0 就一律写“无解”。要看开口方向和不等号：开口向上且“> 0”时解集是 R。
  • 端点开闭写错：≥、≤ 用中括号，>、< 用小括号。
  • “恒成立”问题不会用图象，硬背结论。先画抛物线，答案一眼就能看出来。
自测
  1. 解不等式 x² − 5x + 6 < 0。
  2. 解不等式 −x² + 4x − 3 > 0。
  3. 二次函数 y = x² − 2x + 3 的对称轴和最小值是多少？
对答案
1. (x−2)(x−3) < 0，解集 (2, 3)。 2. 两边乘 −1：x² − 4x + 3 < 0，即 (x−1)(x−3) < 0，解集 (1, 3)。 3. 对称轴 x = 1；代入得 y = 1 − 2 + 3 = 2，最小值 2。

函数的概念：一台“加工机器”

教材 3.1 · 建议 3 天 · 定义域是必考点

必拿分先求定义域
先说人话：函数就是一台加工机器。放进一个 x，按规则 f 加工，吐出一个 y。规则可以是一句话、一个公式、一张表或一条曲线，但必须保证：同一个 x 只能加工出一个 y。
x输入
→
f对应关系
→
y输出（唯一）

例如 f(x) = 2x + 1：输入 1 得到 3，输入 2 得到 5。一个输入只能有一个输出。

左边 1、2 同时对应 3 也允许；右边 x = 1 同时对应 4 和 5，违反“输出唯一”，所以不是函数。

1. 函数三要素

要素含义注意
定义域自变量 x 允许取的所有值先求定义域，再谈其他
对应关系x 按什么规则变成 y公式、表格、图象都算
值域所有输出 y 组成的集合由定义域和对应关系共同决定
两个函数相同 ⇔ 定义域相同 且 对应关系相同。与用什么字母表示无关。

2. 定义域“雷区清单”

结构限制条件例子
分式 1/g(x)g(x) ≠ 0y = 1/(x−1)：x ≠ 1
偶次根式 √g(x)g(x) ≥ 0y = √(x+2)：x ≥ −2
对数 logag(x)g(x) > 0，a > 0 且 a ≠ 1y = log₂(x−1)：x > 1
零次幂 g(x)0g(x) ≠ 0(x−2)0：x ≠ 2
实际问题符合实际意义人数取整数，长度取正数

例 1　求 f(x) = √(x−1) + 1/(x−3) 的定义域。

看解析
根号里要非负：x − 1 ≥ 0，即 x ≥ 1。 分母不能为零：x − 3 ≠ 0，即 x ≠ 3。 两个条件同时满足：定义域为 [1, 3) ∪ (3, +∞)。

例 2　已知 f(x) = { x + 1（x < 0）；x²（x ≥ 0） }，求 f(−2)、f(2)、f(f(−2))。

看解析
f(−2)：−2 < 0，用上面一段，f(−2) = −2 + 1 = −1。 f(2)：2 ≥ 0，用下面一段，f(2) = 2² = 4。 f(f(−2)) = f(−1)：先算里面，−1 < 0，所以 = −1 + 1 = 0。 分段函数求值，先看 x 落在哪一段，从里往外算。
常见错误：
  • 先化简再求定义域。比如先约分再写，可能把原来分母为零的点漏掉。定义域要在原式上求。
  • 几个限制条件之间用“或”而不是“且”。定义域要所有条件同时满足。
  • 分段函数求 f(f(a)) 时从外往里算，顺序反了。
  • 把“f(x+1) 的定义域”理解成 x+1 的范围。它问的始终是 x 的范围。
自测
  1. 求 f(x) = √(2−x) + 1/(x+1) 的定义域。
  2. 已知 f(x) = x² + 1，若 f(a) = 10，求 a。
  3. f(x) = x 与 g(x) = x²/x 是同一个函数吗？
对答案
1. 2 − x ≥ 0 且 x + 1 ≠ 0，即 x ≤ 2 且 x ≠ −1，定义域 (−∞, −1) ∪ (−1, 2]。 2. a² + 1 = 10，a² = 9，a = ±3。 3. 不是。g(x) 的定义域是 x ≠ 0，和 f(x) 的定义域不同。
函数像自动售货机：按一个键，只出对应的商品。一个输入只能有一个输出；不同按键也可能出同一种商品。

函数的性质：上坡、下坡与对称

教材 3.2—3.4 · 建议 5 天 · 选择、填空、大题第(1)问

必拿分图象题
先说人话：单调性看图象是“上坡”还是“下坡”；奇偶性看图象是“左右照镜子”还是“绕原点转半圈”。所有性质都建立在同一个前提上：定义域。

1. 单调性：从左往右，往上还是往下

单调性必须说“在哪个区间上”。离开区间谈单调，没有意义。

2. 奇偶性：先看定义域是否关于原点对称

偶函数：关于 y 轴对称。例：y = x²。

奇函数：关于原点对称。例：y = x³。

偶函数：f(−x) = f(x)　奇函数：f(−x) = −f(x)
前提：定义域关于原点对称，否则直接判断为“非奇非偶”。

3. 五个幂函数，抓住“都过 (1,1)”

函数定义域值域奇偶性单调性
y = xRR奇增
y = x²R[0, +∞)偶(−∞,0] 减，[0,+∞) 增
y = x³RR奇增
y = x−1{x | x ≠ 0}{y | y ≠ 0}奇在 (−∞,0) 和 (0,+∞) 上分别减
y = x1/2[0, +∞)[0, +∞)非奇非偶增

y = x

直线，奇函数，在 R 上单调递增。

y = x²

抛物线，偶函数，最小值 0。

y = x³

奇函数，在 R 上增，越往右越陡。

y = x−1

双曲线，奇函数，两段各自递减。

y = x1/2

只在 x ≥ 0 有图象，非奇非偶，递增。

五张图的曲线都经过点 (1,1)（图中圆点）。分开看形状，再对照上面的表格记定义域与单调性。

例 1　判断 f(x) = x³ + x 的奇偶性。

看解析
定义域是 R，关于原点对称。 f(−x) = (−x)³ + (−x) = −x³ − x = −(x³ + x) = −f(x)。 所以 f(x) 是奇函数。

例 2　已知 f(x) = x² − 2x + 3，x ∈ [0, 3]。求它的单调区间和值域。

看解析
对称轴 x = −b/(2a) = 2/2 = 1，开口向上。 在 [0, 1] 上递减，在 [1, 3] 上递增。 最小值在顶点：f(1) = 1 − 2 + 3 = 2。 最大值看两个端点：f(0) = 3，f(3) = 9 − 6 + 3 = 6，取较大的 6。 值域为 [2, 6]。
常见错误：
  • 单调区间用“∪”连接。应该用“和”或逗号分开写，例如“在 (−∞,0) 和 (0,+∞) 上分别递减”。
  • 判断奇偶性不看定义域。定义域不关于原点对称，直接是非奇非偶。
  • 认为奇函数一定过原点。只有 0 在定义域内时，才有 f(0) = 0。
  • 求闭区间最值时只算顶点，忘了比较两个端点。
自测
  1. 判断 f(x) = x² + 1 的奇偶性。
  2. 判断 f(x) = x³ 的奇偶性。
  3. f(x) = x² 在 [−1, 2] 上是奇函数还是偶函数？
对答案
1. f(−x) = (−x)² + 1 = x² + 1 = f(x)，偶函数。 2. f(−x) = (−x)³ = −x³ = −f(x)，奇函数。 3. 都不是。定义域 [−1, 2] 不关于原点对称，直接判为非奇非偶。
气温曲线上升、下降，就是函数的增、减；蝴蝶左右对称，像偶函数；把图形绕原点转半圈仍重合，像奇函数。

指数与指数函数：每一步都乘同一个数

教材 4.1—4.2 · 建议 3 天 · 运算必考

必拿分图象与单调性
先说人话：指数函数就是“每走一步，就乘同一个数”。细胞每分裂一次数量翻倍，就是 2 的幂；钱按年利率增长，也是这个道理。它长得非常快，所以叫“指数爆炸”。

1. 指数运算：先记这几条

a0 = 1（a ≠ 0）　a−n = 1/an
am/n = n√(am)（a > 0）
am · an = am+n　am ÷ an = am−n
(am)n = amn　(ab)n = anbn

负指数先取倒数，分数指数先想“根号”。例如 82/3 = (2³)2/3 = 2² = 4。

2. 指数函数的图象与性质

两条曲线都过 (0,1)，都在 x 轴上方；a > 1 上升，0 < a < 1 下降。

函数y = ax（a > 1）y = ax（0 < a < 1）
定义域RR
值域(0, +∞)(0, +∞)
定点(0, 1)(0, 1)
单调性增函数减函数
必背：ax 永远大于 0，图象永远在 x 轴上方，x 轴是它的渐近线。底数必须满足 a > 0 且 a ≠ 1。

3. 比较大小：同底看单调，不同底找中间量

同底数 → 用单调性→不同底 → 找 1 或化成同底

例 1　比较 20.3 与 20.5 的大小。

看解析
底数 2 > 1，函数 y = 2x 是增函数。 因为 0.3 < 0.5，所以 20.3 < 20.5。

例 2　计算 82/3 + (1/2)−2。

看解析
82/3 = (2³)2/3 = 2² = 4。 (1/2)−2 = 2² = 4。 原式 = 4 + 4 = 8。
常见错误：
  • 把 a0 写成 0。任何非零数的 0 次方都等于 1。
  • 负指数忘记取倒数：2−3 = 1/8，不是 −8。
  • 认为 ax 可能等于 0 或负数。它恒大于 0。
  • 比较大小不看底数，直接看指数。底数小于 1 时，指数越大反而越小。
自测
  1. 计算 2−3。
  2. 比较 0.5² 与 0.5³ 的大小。
  3. 函数 y = 3x 的定义域和值域分别是什么？
对答案
1. 2−3 = 1/2³ = 1/8。 2. 底数 0.5 在 (0,1) 内，函数递减，所以 0.5² > 0.5³。 3. 定义域 R，值域 (0, +∞)。
细胞分裂：每 20 分钟数量翻倍，2 小时后是原来的 26 倍；复利也是同样的指数增长。

对数与对数函数：把指数“倒着问”

教材 4.3—4.4 · 建议 4 天 · 运算与图象

必拿分真数大于 0
先说人话：对数是指数的“倒着问”。2 的几次方等于 8？答案是 3，写成 log₂8 = 3。指数问“结果是多少”，对数问“要几次方”。
ax = N ⇔ x = logaN
其中 a > 0，a ≠ 1，N > 0。
常用：loga1 = 0，logaa = 1，alogaN = N。

1. 对数运算：三条主线

loga(MN) = logaM + logaN
loga(M/N) = logaM − logaN
logaMk = k logaM
换底：logab = logcb / logca

真数必须大于 0，底数必须大于 0 且不等于 1。这两条是解对数题的第一道检查。

y = ax 与 y = logax 互为反函数，图象关于直线 y = x 对称。

函数y = logax（a > 1）y = logax（0 < a < 1）
定义域(0, +∞)(0, +∞)
值域RR
定点(1, 0)(1, 0)
单调性增函数减函数
对称记忆：指数函数过 (0,1)，对数函数过 (1,0)；定义域和值域互换；两条曲线关于 y = x 对称。

例 1　计算 log₂8 + log₃(1/9)。

看解析
2 的 3 次方是 8，所以 log₂8 = 3。 3 的 −2 次方是 1/9，所以 log₃(1/9) = −2。 原式 = 3 + (−2) = 1。

例 2　计算 log₂3 · log₃4。

看解析
用换底公式：log₃4 = log₂4 / log₂3。 原式 = log₂3 · (log₂4 / log₂3) = log₂4 = 2。

例 3　解方程 log₂(x−1) = 3。

看解析
化成指数形式：x − 1 = 2³ = 8。 解得 x = 9。 检验真数：x − 1 = 8 > 0，成立。所以 x = 9。
常见错误：
  • 忘记“真数大于 0”，解出根不检验。
  • 把 log(M + N) 写成 logM + logN。只有乘法才能拆成加法。
  • 把 logₐ1 和 logₐa 记混：前者是 0，后者是 1。
  • 底数不合法（a ≤ 0 或 a = 1）还在算。
自测
  1. 计算 log₂16。
  2. 计算 lg100（lg 表示以 10 为底）。
  3. 计算 log₃(1/27)。
对答案
1. 2⁴ = 16，所以 log₂16 = 4。 2. 10² = 100，所以 lg100 = 2。 3. 3−3 = 1/27，所以 log₃(1/27) = −3。
地震震级就是对数：能量每变成原来的 10 倍，震级大约加 1；化学里的 pH 值也是对数尺度。

函数的应用：零点与二分法

教材 4.5 · 建议 2 天 · 选择、填空为主

力争分存在定理
先说人话：函数的零点，就是让函数值等于 0 的那个 x。它不是点，是一个数；在图象上，它是曲线与 x 轴交点的横坐标。找零点，就是解方程 f(x) = 0。

1. 零点存在定理：看两端符号

定理：如果函数 f(x) 在闭区间 [a, b] 上的图象连续不断，且 f(a)·f(b) < 0，那么 f(x) 在 (a, b) 内至少有一个零点。
直观理解：一端在 x 轴下方，另一端在上方，曲线要过去，就必然穿过 x 轴。

两端函数值异号，中间至少穿过 x 轴一次。注意：定理只保证“至少一个”，不保证唯一。

2. 二分法：不断对半缩小范围

取中点→算中点函数值→保留异号那一半→重复到够精确

二分法通常考选择或填空，知道“每次把区间缩小一半”就够了，不需要手算很多轮。

每一轮取中点 m，算出 f(m)，保留两端异号的那一半。区间长度依次变为 400 → 200 → 100，每次减半。

3. 四种常见增长模型

模型增长特点生活例子
一次函数 y = kx + b匀速增长出租车按里程计费
二次函数 y = ax²先慢后快正方形边长与面积
指数函数 y = ax（a > 1）爆炸式增长细胞分裂、复利
对数函数 y = logax先快后慢地震震级、pH 值

例 1　判断 f(x) = x² − 2x − 1 在 (2, 3) 内是否有零点。

看解析
f(2) = 4 − 4 − 1 = −1 < 0。 f(3) = 9 − 6 − 1 = 2 > 0。 f(2)·f(3) < 0，且函数图象连续，所以在 (2, 3) 内至少有一个零点。

例 2　判断 f(x) = 2x + x − 4 在 (1, 2) 内是否有零点。

看解析
f(1) = 2 + 1 − 4 = −1 < 0。 f(2) = 4 + 2 − 4 = 2 > 0。 两端异号，图象连续，所以 (1, 2) 内至少有一个零点。
常见错误：
  • 把零点写成坐标 (x, 0)。零点是一个数 x，交点才是 (x, 0)。
  • 认为 f(a)f(b) < 0 就“只有一个”零点。定理只保证至少一个。
  • 忘了“图象连续”这个前提。
  • 由 f(a)f(b) > 0 就断定没有零点。可能有两个。
自测
  1. 函数 y = x² − 4 的零点是什么？
  2. f(x) = x³ + x − 1 在 (0, 1) 内是否有零点？
  3. 二分法每进行一次，区间长度变成原来的多少？
对答案
1. 解 x² − 4 = 0，得 x = ±2。 2. f(0) = −1 < 0，f(1) = 1 > 0，两端异号，有零点。 3. 变成原来的一半。
复利、人口增长前期慢、后期快，是指数模型；对数模型正好相反，先快后慢。

三角函数：圆上的位置

教材 5.1—5.3 · 建议 5 天 · 特殊角与诱导公式必考

必拿分符号易错
先说人话：三角函数就是“圆上的位置”。让一个点从 (1,0) 出发，沿单位圆转一个角 α，它停下来时的横坐标是 cosα，纵坐标是 sinα。角转一圈，sin 和 cos 就循环一次。

1. 角度与弧度：180° = π

角度0°30°45°60°90°180°270°360°
弧度0π/6π/4π/3π/2π3π/22π
弧长 l = |α| r　扇形面积 S = ½ l r = ½ |α| r²
其中 α 用弧度制，r 是半径。

把“长度等于半径的弧”所对的圆心角规定为 1 弧度。所以弧长 l = |α|r，整圆就是 2π 弧度。

单位圆半径是 1，所以 cosα 就是横坐标，sinα 就是纵坐标。

先判断角在第几象限，再决定正负号。符号错了，后面全错。

2. 同角关系与诱导公式

sin²α + cos²α = 1
tanα = sinα / cosα（cosα ≠ 0）

已知一个，可以求另外两个，但开平方时要根据象限选正负号。

sin(π − α) = sinα　cos(π − α) = −cosα
sin(π + α) = −sinα　cos(π + α) = −cosα
sin(−α) = −sinα　cos(−α) = cosα
sin(π/2 − α) = cosα　cos(π/2 − α) = sinα

口诀“奇变偶不变，符号看象限”，配合单位圆理解，不要死背。

3. 特殊角，必须张口就来

α0π/6（30°）π/4（45°）π/3（60°）π/2（90°）
sinα01/2√2/2√3/21
cosα1√3/2√2/21/20
tanα0√3/31√3不存在

例 1　已知 sinα = 3/5，且 α 在第二象限，求 cosα 和 tanα。

看解析
由 sin²α + cos²α = 1：cos²α = 1 − 9/25 = 16/25。 开平方得 cosα = ±4/5。第二象限余弦为负，所以 cosα = −4/5。 tanα = sinα / cosα = (3/5) ÷ (−4/5) = −3/4。

例 2　求 sin(7π/6)。

看解析
7π/6 = π + π/6，在第三象限，正弦为负。 sin(π + α) = −sinα，所以 sin(7π/6) = −sin(π/6) = −1/2。
常见错误：
  • 开平方后忘记根据象限选正负号。sin² + cos² = 1 只能确定平方，不能直接确定符号。
  • 把 tan 的定义域忘了：cosα = 0 时 tanα 不存在，即 α = π/2 + kπ。
  • 角度和弧度混用，例如把 sin30 当成 sin30°。算弧度时必须写 π/6。
  • 诱导公式只记结论，不判断象限，符号经常写反。
自测
  1. 求 sin150°。
  2. 求 cosπ。
  3. 求 tan45°。
  4. 求 sin(−π/6)。
对答案
1. sin150° = sin(180° − 30°) = sin30° = 1/2。 2. cosπ = −1。 3. tan45° = 1。 4. sin(−π/6) = −sin(π/6) = −1/2。
摩天轮座舱的高度随时间按正弦规律变化；钟摆、水车也是周期运动。

三角函数的图象与性质

教材 5.4—5.7 · 建议 6 天 · 大题常考第(1)问

必拿分恒等变换力争
先说人话：把 sin 曲线拉高、压扁、左右挪，就得到 y = A sin(ωx + φ)。A 管高矮，ω 管快慢，φ 管左右。这三件事分清了，这一章就通了一半。

1. 五点法画 y = sin x

五个关键点：0、π/2、π、3π/2、2π 对应的函数值依次是 0、1、0、−1、0。

2. 三种基本三角函数的性质

函数定义域值域周期奇偶性单调递增区间
y = sin xR[−1, 1]2π奇[−π/2 + 2kπ, π/2 + 2kπ]
y = cos xR[−1, 1]2π偶[−π + 2kπ, 2kπ]
y = tan xx ≠ π/2 + kπRπ奇(−π/2 + kπ, π/2 + kπ)

3. y = A sin(ωx + φ)：四个参数看明白

振幅 |A|　周期 T = 2π/|ω|　频率 f = 1/T
初相 φ　相位 ωx + φ　值域 [−|A|, |A|]
最大值 |A|，最小值 −|A|。
变化对图象的影响注意
A 变化上下拉伸，振幅变为 |A|A 为负时还要关于 x 轴翻折
ω 变化横向压缩或拉伸，周期变为 2π/|ω|ω 越大，周期越短
φ 变化左右平移左加右减；平移量是 φ/ω

虚线都是 y = sin x 作对照。左：A = 2，高度翻倍；中：ω = 2，周期减半；右：φ = π/3，图象左移 π/3。

最容易错：y = sin(2x + π/3) 不是向左平移 π/3，而是 sin[2(x + π/6)]，向左平移 π/6。先把 ω 提出来，再读平移量。

4. 恒等变换：背公式，会代入

sin(α ± β) = sinα cosβ ± cosα sinβ
cos(α ± β) = cosα cosβ ∓ sinα sinβ
tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)
sin2α = 2 sinα cosα
cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α

目标 80 分：先把公式背准，会做“给一个特殊角拆成两个角”的题；复杂的证明和变形可以暂时放一放。

例 1　求 y = 2sin(2x − π/3) 的振幅、周期、最大值和单调递增区间。

看解析（重点题，建议做两遍）
振幅 |A| = 2；周期 T = 2π/|ω| = 2π/2 = π；最大值 2。 正弦函数在 [−π/2 + 2kπ, π/2 + 2kπ] 上递增。 令 −π/2 + 2kπ ≤ 2x − π/3 ≤ π/2 + 2kπ。 各部分加 π/3：−π/6 + 2kπ ≤ 2x ≤ 5π/6 + 2kπ。 除以 2：[−π/12 + kπ, 5π/12 + kπ]（k ∈ Z）。

例 2　求 sin75°。

看解析
75° = 45° + 30°，用两角和公式。 sin75° = sin45°cos30° + cos45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4。

例 3　已知 sinα = 3/5，α ∈ (0, π/2)，求 sin2α 和 cos2α。

看解析
α 在第一象限，cosα = √(1 − 9/25) = 4/5。 sin2α = 2 sinα cosα = 2 × (3/5) × (4/5) = 24/25。 cos2α = 1 − 2sin²α = 1 − 2 × (9/25) = 7/25。
常见错误：
  • 周期写成 2π/ω，忘记加绝对值。ω 为负时周期仍是 2π/|ω|。
  • 平移量直接读 φ，没有除以 ω。
  • tan 的单调区间用“∪”把两段连起来。必须分开写。
  • 把 sin(α + β) 写成 sinα + sinβ。这是最经典的错误，三角函数不能“分配”。
自测
  1. 求 y = 3sin(2x + π/6) 的振幅、周期和最大值。
  2. 求 sin15°。
  3. 已知 sinα = 1/3，求 cos2α。
对答案
1. 振幅 3；周期 2π/2 = π；最大值 3。 2. sin15° = sin(45° − 30°) = (√2/2)(√3/2) − (√2/2)(1/2) = (√6 − √2)/4。 3. cos2α = 1 − 2sin²α = 1 − 2/9 = 7/9。
交流电的电压可以写成 u = Um sin(ωt + φ)：A 是峰值，ω 是角频率，φ 是初相。

三、解答题

13.（画数轴 2 分）A∩B = [1, 3)（3 分）；A∪B = [−2, +∞)（3 分）；∁UA = (−∞, −2) ∪ [3, +∞)（2 分）。
注意：−2 属于 A，补集不含 −2；3 不属于 A，补集含 3。

14.（1）令 x² − 2x − 3 = 0，得 (x−3)(x+1) = 0，零点为 x = −1 和 x = 3（3 分）。
（2）(x−3)(x+1) ≤ 0，解集 [−1, 3]（3 分）。
（3）对称轴 x = 1，最小值 f(1) = −4；端点 f(0) = −3，f(3) = 0，所以值域 [−4, 0]（4 分）。

15.设垂直于墙的边为 x m，则平行于墙的边为 (20−2x) m（2 分）。
面积 S = x(20−2x) = 2x(10−x)（2 分）。
因为 x > 0，10−x > 0，所以 x(10−x) ≤ ((x + 10 − x)/2)² = 25（3 分）。
故 S ≤ 50，当且仅当 x = 10−x，即 x = 5 时取等号（2 分）。
答：围成 5 m × 10 m 时面积最大，最大面积为 50 m²（1 分）。

16.（1）振幅 2，周期 T = 2π/2 = π，最大值 2（3 分）。
（2）令 −π/2 + 2kπ ≤ 2x − π/3 ≤ π/2 + 2kπ，解得 −π/12 + kπ ≤ x ≤ 5π/12 + kπ，所以递增区间为 [−π/12 + kπ, 5π/12 + kπ]（k ∈ Z）（5 分）。
（3）f(π/2) = 2sin(π − π/3) = 2sin(2π/3) = 2 × (√3/2) = √3（2 分）。

集合与逻辑

A∩B：公共部分
A∪B：全部合并
∁UA：U 里去掉 A
n 个元素：子集 2n 个

¬(∀x, p) ⇔ ∃x, ¬p

不等式

a > b，c < 0 ⇒ ac < bc
(a+b)/2 ≥ √(ab)（a,b > 0）
ab ≤ ((a+b)/2)²
一正、二定、三相等

二次函数

Δ = b² − 4ac
对称轴 x = −b/(2a)
顶点 (−b/(2a), (4ac−b²)/(4a))
a > 0：大于取两边，小于取中间

函数性质

分母 ≠ 0；偶次根 ≥ 0；真数 > 0
偶：f(−x) = f(x)
奇：f(−x) = −f(x)
单调区间不能写“∪”

指数

a0 = 1　a−n = 1/an
am/n = n√(am)
aman = am+n
y = ax：R → (0,+∞)，过 (0,1)

logab = logcb / logca

集合求子集时漏掉空集A ⊆ B 求参数，先考虑 A = ∅
