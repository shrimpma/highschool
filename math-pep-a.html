第一章 集合与常用逻辑用语

教材 p.4–38 · 建议用时：4–5 天 · 题型：选择填空为主
得分优先级 ★★★☆☆ · 约12分
本章定位（目标100） 送分章。集合运算、充分必要条件、量词否定——熟练即可。难题少，丢分多为符号写错、端点开闭、否定漏写。

1. 核心概念速览

知识点优先级必会内容常见失分
集合三要素 必拿 确定性、互异性、无序性；∈ / ∉ 互异性漏验（如 {a, a²}）
子集 / 真子集 / 空集 必拿 ⊆、⊊、∅ 是任何集合的子集 空集忘记算子集个数
交并补 必拿 A∩B、A∪B、∁ᵤA；文氏图 补集相对全集搞错
充分 / 必要 / 充要 必拿 「谁推出谁」；充分不必要 vs 必要不充分 方向记反（最易错）
量词否定 力争 ∀ 否定为 ∃；∃ 否定为 ∀；结论取反 只否定量词不否定结论

2. 对比图：充分 vs 必要（死记口诀）

充分条件（⇒）

有它 就够了（充分）→ 能推出结论

若 p ⇒ q，则 p 是 q 的充分条件

口诀：前推后 → 前是后的充分

必要条件（⇐）

没它 不行（必要）← 结论能反推条件

若 p ⇒ q，则 q 是 p 的必要条件

口诀：前推后 → 后是前的必要

充要关系四象限（考试直接套）

做题先判断「能否互相推出」，再对号入座

3. 集合运算对照

运算符号含义区间例子
交集A ∩ B既属于A又属于B[1,3]∩[2,5]=[2,3]
并集A ∪ B属于A或属于B[1,3]∪[2,5]=[1,5]
补集∁ᵤA在全集U中不属于AU=ℝ, A=(0,1], ∁ᵤA=(-∞,0]∪(1,+∞)
自测（目标100必对）

「x>1」是「x>0」的什么条件？

看答案

充分不必要条件。因为 x>1 ⇒ x>0，但 x>0 ⇏ x>1。

第二章 一元二次函数、方程和不等式

教材约 p.39–61 · 建议用时：5–6 天 · 贯穿后续函数章
得分优先级 ★★★★☆ · 约18分
本章定位（目标100） 工具章。基本不等式求最值、二次不等式解集、根的分布——期中必考。后面指数/对数不等式也靠这里的「同解变形」习惯。

1. 不等式性质 vs 等式性质（对比）

操作等式不等式易错
两边加同一数成立成立—
两边乘正数成立方向不变—
两边乘负数成立必须变号忘记变号
两边取倒数一般可同号才可，且变号乱取倒数
两边平方需讨论两边非负才能平方漏条件

2. 基本不等式（必拿分公式）

若 a>0, b>0，则 (a+b)/2 ≥ √(ab)，当且仅当 a=b 时等号成立。

「和定积最大」

a+b = 定值 S → 积 ab 最大为 (S/2)²

用于：围栏、分割、造价最省等

「积定和最小」

ab = 定值 P → 和 a+b 最小为 2√P

用于：正数积一定，求最小和

✗ 等号必须检查 目标100的学生最爱丢这2分：写出最值却不验证等号能否取到（a、b是否为正且相等）。

3. 二次「三位一体」对比图

同一抛物线看方程 / 不等式 / 函数

口诀（开口向上）：大于取两边，小于取中间

4. 二次不等式解题流程（中档必拿）

步骤做什么注意
①移项化为 ax²+bx+c □ 0二次项系数最好 >0（两边同乘-1要变号）
②算 Δ = b²−4acΔ<0 / =0 / >0 三种讨论
③求根或配方 / 因式分解写清开闭区间
④结合图象写解集用集合或区间表示
自测

解不等式：x² − 3x − 4 > 0

看答案

因式分解 (x−4)(x+1)>0 → 解集 (-∞,−1)∪(4,+∞)

第三章 函数的概念与性质

教材约 p.62–105 · 建议用时：7–8 天 · 高中数学主线起点
得分优先级 ★★★★★ · 约22分
本章定位（目标100） 全书核心。定义域、值域、单调性、奇偶性、分段函数——选择填空大户，解答题第(1)(2)问常考。学好这章，第4、5章事半功倍。

1. 函数三要素对比

定义域 · 对应关系 · 值域

  • 定义域：自变量取值集合（先求！）
  • 对应关系：怎么对应（解析/图象/表格）
  • 值域：函数值集合（依赖前两者）

两个函数相等 ⇔

定义域相同 且 对应关系相同

值域相同不能说明函数相等（常设陷阱）

2. 定义域「雷区清单」

结构限制条件优先级
分母≠ 0必拿
√g(x)（偶次根）g(x) ≥ 0必拿
logₐ f(x)f(x)>0，且 a>0,a≠1必拿
实际问题符合实际意义（正数、整数等）力争

3. 单调性 vs 奇偶性（对比表）

性质定义（用定义证明）图象特征运算注意
增函数 x₁<x₂ ⇒ f(x₁)<f(x₂) 从左到右上升 复合：同增异减
减函数 x₁<x₂ ⇒ f(x₁)>f(x₂) 从左到右下降 外减内增 → 整体减
奇函数 f(−x)=−f(x)，定义域关于原点对称 关于原点对称 f(0)=0（0在定义域内）
偶函数 f(−x)=f(x)，定义域关于原点对称 关于 y 轴对称 奇±奇=奇；偶±偶=偶

奇偶性快速判断流程

幂函数 y=x^α 五虎将对比

函数定义域奇偶在(0,+∞)
y=xℝ奇增
y=x²ℝ偶增
y=x³ℝ奇增
y=x^{1/2}[0,+∞)非增
y=x^{−1}{x|x≠0}奇减

记忆：过定点 (1,1)；先画第一象限再谈对称。

✓ 单调性证明得分模板（解答题） 设 x₁<x₂ → 作差 f(x₁)−f(x₂)（或作商）→ 变形判号 → 下结论。步骤完整即使算错中间，过程分也能到手。

第四章 指数函数与对数函数

教材约 p.106–169 · 建议用时：8–10 天 · 提分主战场
得分优先级 ★★★★★ · 约24分
本章定位（目标100） 分值高、题型固定。指数对数互化、图象性质、大小比较、零点与二分法——把「底数分类」练熟，中档题就能稳定得分。

1. 指数 vs 对数：一张表打通

对比项指数函数 y=ax对数函数 y=logax
底数条件a>0 且 a≠1同左
定义域ℝ(0, +∞)
值域(0, +∞)ℝ
过定点(0, 1)(1, 0)
a>1 时增函数增函数
0<a<1 时减函数减函数
关系互为反函数 · 图象关于 y=x 对称

图象对比：a>1 与 0<a<1

实线 a>1（增）；虚线 0<a<1（减）。指数值恒为正，不穿过 x 轴；对数定义域永远在 y 轴右侧。

2. 运算法则对照（必背）

指数

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ

对数

logₐ(MN)=logₐM+logₐN
logₐ(M/N)=logₐM−logₐN
logₐ(Mᵏ)=k logₐM
换底：logₐb = lgb / lga
互化核心：a^{logₐ N} = N（N>0）；logₐ(aᵏ)=k

3. 大小比较「三板斧」（中档选择）

方法适用做法
① 图象 / 单调性同底化为同底，直接比指数或真数
② 中间量异底难比夹 1、0、1/2 等特殊值
③ 作商法/作差法接近的数比与 1 的大小 / 差的正负

4. 函数零点与二分法（4.5）

零点存在定理

f 在 [a,b] 连续，且 f(a)·f(b)<0 ⇒ (a,b) 内至少一零点

易错 「至少」不是「只有」；条件不充分时不能判定无零点。

二分法步骤

  1. 取中点 x₀=(a+b)/2
  2. 看 f(x₀) 符号，收缩区间
  3. 直到区间长度 < 精度
自测

比较：log₂ 3 与 log₃ 2 的大小。

看答案

令 a=log₂3>1，b=log₃2∈(0,1)，故 log₂3 > log₃2。或：log₂3·log₃2=log₂2=1，且两者一大于1一小于1。

第五章 三角函数

教材约 p.170–末 · 建议用时：10–12 天 · 与第4章并列主战场
得分优先级 ★★★★★ · 约24分
本章定位（目标100） 内容最多，但考法高度套路化：弧度换算、诱导公式、同角关系、Asin(ωx+φ) 性质。把「公式会用」做到位，24分里拿 18+ 很现实；压轴三角恒等变换可部分放弃。

1. 弧度制 vs 角度制

π rad = 180°　⇒　1° = π/180 rad，1 rad = 180°/π
角度0°30°45°60°90°180°360°
弧度0π/6π/4π/3π/2π2π

2. 同角关系 + 诱导公式（得分发动机）

同角基本关系

sin²θ + cos²θ = 1
tanθ = sinθ / cosθ
1 + tan²θ = sec²θ

诱导口诀

奇变偶不变，符号看象限

对 π/2±α、π±α、3π/2±α、2π±α 等：先看 k·π/2 的「奇偶」，再定名，最后看 α 所在象限原函数符号。

单位圆：象限符号（ASTC）

3. y = A sin(ωx + φ) 参数对比（大题必考）

参数意义怎么求对图象的影响
A振幅|A| = (ymax−ymin)/2|A| 越大，纵向拉伸
ω决定周期T = 2π / |ω||ω|↑ 周期↓，横向压缩
φ初相由特殊点或平移得出左加右减（对 x）
φ/ω水平偏移—相对 y=Asin(ωx) 的平移量
✓ 五点法作图（必拿步骤分） 令 ωx+φ 依次取 0, π/2, π, 3π/2, 2π → 解出五个 x → 列表描点连线。期末大题几乎标配。

4. 三角恒等变换：目标100学什么

公式优先级说明
两角和差：sin(A±B), cos(A±B)必拿最常用，选择填空高频
tan(A±B)力争会推会用即可
二倍角必拿sin2α, cos2α 三种形式
辅助角 / 复杂恒等变形可放压轴向，目标100够用即可
二倍角：sin2α=2sinαcosα；　cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α
自测

求 y=2sin(2x − π/3) 的周期、振幅、初相。

看答案

振幅 A=2；ω=2 ⇒ T=π；初相 φ=−π/3。
