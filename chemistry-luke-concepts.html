易混淆概念辨析

菏泽一中高一 · 基础补强专用 · 打印后遮住“辨析”自测

一、物质的量（n）——“箱数”

生活化比喻：你去买鸡蛋，一个一个数太慢，于是规定“1箱 = 100个”。化学里的微观粒子太小太多，科学家规定“1 mol = 6.02×10²³个”。所以物质的量（n）就是“这堆东西相当于几箱”，摩尔（mol）就是“箱”这个单位。

必须分清的三组概念

概念它是什么它不是什么
物质的量（n） 一个整体名词，表示“含一定数目粒子的集合体”，单位是 mol 不是质量（不是多少克），不是数量（不是多少个）
摩尔（mol） 物质的量的单位，简称摩 不是物理量本身，不能说“摩尔是物质的量”
摩尔质量（M） 1 mol 物质的质量，单位 g/mol，数值上等于相对分子质量 不是相对分子质量——相对分子质量没有单位，摩尔质量有单位 g/mol
“物质的量”四个字是一个整体，不能拆开理解，更不能说“1 mol 氢”这种含糊表述——必须指明微粒种类，说“1 mol H”或“1 mol H₂”。
摩尔只能用于微观粒子（分子、原子、离子、电子等），不能说“1 mol 大米”“1 mol 小米”。
阿伏伽德罗常数 NA 本身有单位 mol⁻¹，只说“6.02×10²³”是错误的，必须说 6.02×10²³ mol⁻¹。

二、物质分类——“名字会骗人”

生活化比喻：“纯碱”听起来像碱，“铅笔”听起来含铅。化学里很多物质的“俗名”和“分类名”是两回事，看名字猜类别，是最容易丢分的地方。

最经典的三个“名不副实”

物质俗名/听起来像实际类别为什么
Na₂CO₃ “纯碱” 盐（不是碱） 纯碱是 Na₂CO₃ 的俗名，它电离出的阴离子是 CO₃²⁻，不是 OH⁻，所以属于盐类
NaHSO₄ 能电离出 H⁺ 酸式盐（不是酸） 酸的定义要求电离出的阳离子全部是 H⁺，NaHSO₄ 还电离出 Na⁺，所以是盐
O₂ 和 O₃ 混合 只含氧元素 混合物（不是纯净物） 只由一种元素组成的物质不一定是纯净物，O₂ 和 O₃ 是两种不同的单质混在一起

氧化物分类的“两个不一定”

说法对不对反例 / 解释
酸性氧化物一定是非金属氧化物 错 Mn₂O₇ 是金属氧化物，但它是酸性氧化物
非金属氧化物一定是酸性氧化物 错 CO、NO 是非金属氧化物，但它们不是酸性氧化物（不能与碱反应只生成盐和水）
碱性氧化物一定是金属氧化物 对 碱性氧化物定义上就是金属氧化物（但金属氧化物不一定都是碱性氧化物，如 Mn₂O₇）
“纯碱”是盐不是碱；“酸性氧化物”不一定是非金属氧化物，非金属氧化物也不一定是酸性氧化物。

三、离子反应——“拆不拆，看身份”

生活化比喻：离子方程式就像给反应“拍合照”。只有真正在溶液里自由移动的离子才能入镜；沉淀、气体、水、弱电解质这些“宅在家里不出来的”，必须写化学式，不能拆成离子。

书写离子方程式的“拆与不拆”

物质类型能不能拆成离子典型例子
强酸、强碱、可溶性盐 拆 HCl → H⁺ + Cl⁻；NaOH → Na⁺ + OH⁻
弱酸、弱碱、水 不拆（写化学式） CH₃COOH、NH₃·H₂O、H₂O
沉淀、气体 不拆（写化学式，标 ↓ 或 ↑） BaSO₄↓、CO₂↑
微溶物 看状态：澄清溶液拆，悬浊液不拆 澄清石灰水写 OH⁻ + H⁺；石灰乳写 Ca(OH)₂

最容易写错的“一个离子方程式”

H⁺ + OH⁻ = H₂O 不能代表所有中和反应。它只能表示“酸根离子和碱的阳离子都不参与反应”的强酸强碱中和。Ba(OH)₂ 与 H₂SO₄ 的反应中，Ba²⁺ 和 SO₄²⁻ 也会结合成沉淀，必须单独写出。
与“量”有关的离子反应，按“以少定多”原则：把量少的那种物质设为 1 mol，再根据它来确定其他离子的配比。

四、氧化还原反应——“升失氧，降得还”

生活化比喻：氧化还原反应的本质是电子的“搬家”。一个原子把电子交出去，化合价就“升高”，自己被氧化（当还原剂）；另一个原子把电子接过来，化合价就“降低”，自己被还原（当氧化剂）。化合价变化只是电子搬家的“表面痕迹”。

特征 vs 实质（最容易混）

特征（肉眼可见）实质（真正原因）
是什么 反应前后元素化合价发生变化 发生了电子的转移（得失或偏移）
判断用途 判断一个反应是不是氧化还原反应，就看化合价有没有变 解释“为什么化合价会变”

和四种基本反应类型的关系

反应类型是否一定是氧化还原反应
置换反应一定是
复分解反应一定不是
化合反应不一定（有单质参加的化合反应才是，如 H₂ + Cl₂ → 2HCl；但 H₂O + SO₃ → H₂SO₄ 不是）
分解反应不一定（有单质生成的分解反应才是，如 2KClO₃ → 2KCl + 3O₂↑；但 CaCO₃ → CaO + CO₂↑ 不是）
有氧元素参加 ≠ 氧化还原反应。例如 CO₂ + H₂O = H₂CO₃ 有氧参加，但所有元素化合价都没变，不是氧化还原反应。
有单质生成/参加 ≠ 一定是氧化还原反应。3O₂ = 2O₃ 有单质参加也有单质生成，但化合价没变，不是氧化还原反应。

五、胶体与丁达尔效应——“光走过的路”

生活化比喻：胶体是“粒子大小刚好卡在中间”的分散系：比溶液里的小粒子大，比浊液里的大颗粒小（1~100 nm）。当一束光穿过胶体时，这些“中等个头”的粒子会把光散射开，从侧面能看到一条光亮的“通路”——这就是丁达尔效应。溶液粒子太小，光直接穿过，看不到这条路。

三种分散系的最简区分

分散系分散质粒子直径丁达尔效应生活例子
溶液< 1 nm无盐水、糖水
胶体1 ~ 100 nm有（最简便的鉴别方法）豆浆、雾、Fe(OH)₃ 溶胶
浊液> 100 nm无泥水
丁达尔效应是区分胶体和溶液的最简便方法，但不能区分胶体和浊液（浊液也没有丁达尔效应）。不过高中阶段主要用它来鉴别胶体与溶液。
雾是胶体，不是水蒸气。水蒸气是气态水分子，肉眼看不见；雾是空气中悬浮的小液滴，粒子大小在胶体范围内，所以清晨树林里的“光柱”是丁达尔效应。
