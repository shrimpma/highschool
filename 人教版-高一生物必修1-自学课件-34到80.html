概念混淆

01

第1章 走近细胞

先判断：是不是细胞，属于哪类细胞

这一章不靠死记名词，靠排除法拿分：病毒、原核、真核、生命系统层次，四类判断要形成条件反射。

A级 选择、识图 8-10分

必背骨架

  • 生命活动离不开细胞；细胞是生命系统最基本的结构和功能单位。
  • 生命系统层次：细胞→组织→器官→系统→个体→种群→群落→生态系统→生物圈；植物没有系统层次。
  • 原核细胞没有核膜包被的细胞核，只有核糖体这一种细胞器；真核细胞有核膜和多种细胞器。
  • 原核生物：细菌、蓝细菌、支原体、衣原体、立克次氏体、放线菌。真核生物：酵母菌、霉菌、食用菌、藻类、原生动物、植物、动物。
  • 细胞学说揭示细胞的统一性；病毒没有细胞结构，必须寄生在活细胞中。
  • 显微镜放大倍数＝目镜×物镜；放大的是长度或宽度，不是面积。

高频题型

原核/真核生物判断：蓝细菌、酵母菌、水绵、草履虫是高频选项。换高倍镜：视野变暗、细胞变大、数目变少；一行细胞数按倍数反比，视野总面积按倍数平方反比。生命系统层次：单细胞生物的细胞既是细胞层次，也是个体层次；植物无系统；病毒不属于生命系统结构层次。细胞统一性：都有细胞膜、细胞质、核糖体，都以DNA为遗传物质。

显微镜计算模型：放大倍数变为原来的 k 倍，视野直径变为 1/k，一行看到的细胞数变为 1/k；视野面积变为 1/k²，看到的细胞总数变为 1/k²。

易错点

  • 蓝细菌就是旧教材里的“蓝藻”，属于原核生物，不是绿色藻类。
  • 原核细胞没有线粒体，但很多仍能进行有氧呼吸，相关酶可分布在细胞膜上。
  • 有细胞壁不等于植物细胞：细菌、真菌也有细胞壁。
  • 病毒没有细胞结构，不能独立完成生命活动。

必刷题

先做，再看解析
选择下列生物中，属于原核生物的是
  1. 酵母菌
  2. 蓝细菌
  3. 水绵
  4. 草履虫

答案：B

解析：蓝细菌没有核膜包被的细胞核，属于原核生物；酵母菌是真菌，水绵是绿藻，草履虫是原生动物，均为真核生物。

选择用10×目镜和10×物镜观察，视野中一行看到8个细胞。若换用40×物镜，其他条件不变，一行约看到
  1. 2个
  2. 4个
  3. 8个
  4. 32个

答案：A

解析：放大倍数变为原来的4倍，视野直径变为原来的1/4，因此一行细胞数约为8÷4＝2个。

选择下列关于生命系统结构层次的叙述，正确的是
  1. 病毒属于生命系统的个体层次
  2. 植物没有系统层次
  3. 单细胞生物没有细胞层次
  4. 一个池塘中所有鱼构成群落

答案：B

解析：病毒无细胞结构，不属于生命系统结构层次；单细胞生物既是细胞层次也是个体层次；池塘中所有生物才构成群落。

02

第2章 组成细胞的分子

把“元素—化合物—功能”连成一条线

这是第一次月考最容易拉开差距的一章。不要只背“有什么”，要会判断“缺了什么会怎样”“检测出现什么颜色”“蛋白质怎么算”。

A+级 选择、填空、计算 20-25分

必背骨架

  • 大量元素：C、H、O、N、P、S、K、Ca、Mg；微量元素：Fe、Mn、Zn、Cu、B、Mo。C是最基本元素。
  • 细胞鲜重含量最多的化合物是水，干重含量最多的化合物是蛋白质；鲜重含量最多的元素是O，干重含量最多的元素是C。
  • 自由水是良好溶剂，参与运输和生化反应；结合水是细胞结构的重要组成成分。自由水/结合水比值高，代谢旺盛；比值低，抗逆性强。
  • 无机盐多以离子形式存在，维持渗透压、酸碱平衡和细胞形态；Mg是叶绿素组成成分，Fe是血红素成分。
  • 糖类是主要能源物质；葡萄糖是主要能源物质，淀粉和糖原分别是植物、动物储能多糖，纤维素是植物细胞壁成分，几丁质存在于甲壳类和真菌细胞壁。
  • 脂肪是良好储能物质，磷脂是膜的重要成分，固醇包括胆固醇、性激素和维生素D。
  • 还原糖与斐林试剂水浴加热生成砖红色沉淀；蛋白质与双缩脲试剂呈紫色；脂肪被苏丹III染成橘黄色；淀粉遇碘变蓝。
  • 氨基酸通过脱水缩合形成肽键；n个氨基酸形成m条肽链，脱去n-m个水，形成n-m个肽键。
  • 蛋白质多样性：氨基酸种类、数目、排列顺序，以及肽链盘曲折叠形成的空间结构不同。
  • 蛋白质功能：结构、催化、运输、信息传递、免疫、运动、调节等。
  • DNA与RNA：五碳糖不同（脱氧核糖/核糖），碱基不同（T/U）；核酸储存、传递和表达遗传信息。

高频题型

元素与化合物含量：鲜重/干重、主要元素/基本元素/最基本元素。水与无机盐：自由水/结合水、缺Mg/Fe/ Ca的症状、生理盐水浓度。糖类与脂质：还原糖、二糖、多糖、脂肪与磷脂、固醇。蛋白质计算：肽键数、脱水数、相对分子质量、游离氨基/羧基。核酸：DNA/RNA的组成、分布、遗传物质判断。颜色反应：试剂、条件、现象、材料选择。
肽键数＝脱水数＝n－m
相对分子质量＝n·a－18(n－m)－2×二硫键数
至少游离氨基数/羧基数＝肽链数

易错点

  • 斐林试剂需要水浴加热，双缩脲试剂不需要加热，两者成分浓度和使用顺序不同。
  • 西瓜、番茄有颜色，不适合做还原糖检测材料；苹果、梨更适合。
  • 脂肪检测不一定都要显微镜，组织样液可直接加苏丹III观察颜色。
  • 高温使蛋白质变性，破坏的是空间结构，肽键一般没有断裂。
  • 核酸不是“只有DNA”，细胞生物的遗传物质是DNA，病毒的遗传物质是DNA或RNA。

必刷题

先做，再看解析
计算某蛋白质由2条肽链、100个氨基酸组成，形成过程中脱去的水分子数和形成的肽键数分别是
  1. 98、98
  2. 99、99
  3. 100、100
  4. 98、100

答案：A

解析：肽键数＝脱水数＝氨基酸数－肽链数＝100－2＝98。

选择人和动物细胞中重要的储能多糖是
  1. 淀粉
  2. 糖原
  3. 纤维素
  4. 蔗糖

答案：B

解析：糖原是动物细胞中的储能多糖；淀粉是植物细胞储能多糖；纤维素是植物细胞壁成分；蔗糖是二糖。

选择检测生物组织中的还原糖时，斐林试剂的正确使用条件是
  1. 常温静置
  2. 水浴加热
  3. 酒精灯直接加热
  4. 先加盐酸

答案：B

解析：还原糖与斐林试剂反应需要50-65℃水浴加热，生成砖红色沉淀。

选择DNA与RNA在化学组成上的主要区别是
  1. 五碳糖和碱基不同
  2. 磷酸不同
  3. 元素种类不同
  4. 空间结构完全相同

答案：A

解析：DNA含脱氧核糖和碱基T，RNA含核糖和碱基U；两者都含磷酸，元素种类相同。

选择蛋白质多样性的原因不包括
  1. 氨基酸种类不同
  2. 氨基酸数目不同
  3. 氨基酸排列顺序不同
  4. 肽键的元素组成不同

答案：D

解析：肽键的元素组成相同。蛋白质多样性来自氨基酸种类、数目、排列顺序以及肽链的空间结构。

03

第3章 细胞的基本结构

看到结构，马上想到功能

这一章的选择题和识图题很密。复习时不要孤立背细胞器，要按“膜结构—功能—典型细胞”三列整理。

A级 识图、分泌蛋白 15-20分

必背骨架

  • 细胞膜主要由脂质（磷脂）和蛋白质组成，基本支架是磷脂双分子层；结构特点是有一定流动性，功能特点是选择透过性。
  • 糖蛋白位于细胞膜外侧，与识别、信息交流有关。
  • 细胞壁：植物纤维素和果胶；真菌几丁质；细菌肽聚糖；动物无。
  • 线粒体：双层膜，内膜向内折叠形成嵴，是有氧呼吸主要场所；叶绿体：双层膜，类囊体薄膜上进行光反应，基质中进行暗反应。
  • 内质网：蛋白质加工、脂质合成；高尔基体：蛋白质加工、分类、包装、发送；核糖体：蛋白质合成；溶酶体：消化；液泡：调节渗透压、储存；中心体：与纺锤体形成有关。
  • 分泌蛋白路径：核糖体→内质网→高尔基体→细胞膜；线粒体供能。
  • 细胞核：核膜、核孔、核仁、染色质；是遗传信息库，是细胞代谢和遗传的控制中心。

高频题型

细胞膜流动镶嵌模型：磷脂双分子层、蛋白质分布、糖蛋白位置。细胞器结构与功能匹配：双层膜、单层膜、无膜三类。分泌蛋白合成与分泌：路径、膜面积变化、线粒体供能。细胞核结构与功能：核孔、核仁、染色质。制备细胞膜：哺乳动物成熟红细胞放入清水，吸水涨破。

分泌蛋白膜面积模型：内质网膜面积减小，高尔基体膜面积先增大后减小，细胞膜面积增大；线粒体提供能量，膜融合体现细胞膜的流动性。

易错点

  • 高尔基体不是蛋白质合成的场所，核糖体才是。
  • 溶酶体内的水解酶由核糖体合成，经内质网和高尔基体加工。
  • 中心体存在于动物细胞和低等植物细胞，高等植物细胞没有。
  • 核孔不是“什么都能过”，DNA一般不能通过，mRNA和蛋白质可以通过。
  • 植物细胞不一定都有叶绿体，比如根尖细胞。

必刷题

先做，再看解析
选择细胞膜的基本支架是
  1. 蛋白质
  2. 磷脂双分子层
  3. 糖蛋白
  4. 胆固醇

答案：B

解析：流动镶嵌模型认为磷脂双分子层构成细胞膜的基本支架，蛋白质镶在、嵌入或贯穿其中。

选择分泌蛋白合成和分泌过程中，依次经过的细胞结构是
  1. 核糖体→内质网→高尔基体→细胞膜
  2. 内质网→核糖体→高尔基体→细胞膜
  3. 高尔基体→内质网→核糖体→细胞膜
  4. 核糖体→高尔基体→内质网→细胞膜

答案：A

解析：分泌蛋白在核糖体上合成，进入内质网加工，再经高尔基体加工、分类和包装，最后通过囊泡运到细胞膜分泌出去。

选择与植物细胞壁形成有关的细胞器是
  1. 中心体
  2. 高尔基体
  3. 溶酶体
  4. 核糖体

答案：B

解析：高尔基体与植物细胞壁的形成有关，参与纤维素等多糖的合成和分泌。

选择细胞核中与核糖体形成有关的结构是
  1. 核膜
  2. 核孔
  3. 核仁
  4. 染色质

答案：C

解析：核仁与rRNA的合成以及核糖体的形成有关。

第4章 细胞的物质输入和输出

先看方向，再看载体，最后看能量

跨膜运输的判断有固定顺序：是否耗能、是否需要载体、是否逆浓度。质壁分离则是实验题的高频母题。

A级 选择、实验 12-15分

必背骨架

  • 被动运输：高浓度→低浓度，不耗能；自由扩散（O2、CO2、甘油、乙醇、苯）和协助扩散（葡萄糖进入红细胞、水通道）。
  • 主动运输：低浓度→高浓度，需载体蛋白和能量；如小肠上皮细胞吸收葡萄糖、氨基酸，肾小管重吸收葡萄糖，Na+/K+泵。
  • 胞吞/胞吐：大分子或颗粒，依赖膜的流动性，耗能。
  • 渗透作用：水分子通过半透膜，从低浓度溶液向高浓度溶液扩散。
  • 动物细胞：等渗、低渗（吸水涨破）、高渗（失水皱缩）。
  • 植物细胞质壁分离：外界溶液浓度大于细胞液浓度，原生质层伸缩性大，细胞壁伸缩性小；活的成熟植物细胞。
  • 质壁分离复原：细胞仍活，外界溶液浓度降低或溶质进入细胞。

高频题型

自由扩散、协助扩散、主动运输的判断。影响运输速率的因素：浓度差、载体数量、能量、温度。质壁分离与复原的条件、现象、自动复原。细胞膜选择透过性与细胞壁全透性的区别。胞吞、胞吐与膜流动性的关系。

运输方式判断：先看是否逆浓度，再看是否耗能，最后看是否需要载体。逆浓度且耗能→主动运输；顺浓度且需载体→协助扩散；顺浓度且不需载体→自由扩散。

易错点

  • 葡萄糖进入红细胞是协助扩散，进入小肠上皮细胞通常是主动运输。
  • 水分子跨膜运输既可通过自由扩散，也可通过水通道蛋白协助扩散。
  • 质壁分离的内因是原生质层和细胞壁伸缩性不同，外因是外界溶液浓度大于细胞液浓度。
  • 死细胞不能发生质壁分离，因为原生质层失去选择透过性。
  • KNO3、尿素等溶液可能引起质壁分离后自动复原，不是“细胞死了”。

必刷题

先做，再看解析
选择葡萄糖进入红细胞的方式是
  1. 自由扩散
  2. 协助扩散
  3. 主动运输
  4. 胞吞

答案：B

解析：葡萄糖进入红细胞需要载体蛋白，但不消耗能量，属于协助扩散。

选择植物细胞发生质壁分离的内因是
  1. 外界溶液浓度大于细胞液浓度
  2. 原生质层具有选择透过性，且原生质层和细胞壁伸缩性不同
  3. 细胞壁是全透性的
  4. 细胞液浓度大于外界溶液浓度

答案：B

解析：内因是原生质层相当于半透膜，且原生质层伸缩性大于细胞壁；外界溶液浓度大于细胞液浓度是外因。

选择用适宜浓度的KNO3溶液处理紫色洋葱鳞片叶外表皮细胞，一段时间后可观察到
  1. 只发生质壁分离
  2. 质壁分离后自动复原
  3. 只发生复原
  4. 细胞立即死亡

答案：B

解析：K+和NO3-可进入细胞，使细胞液浓度逐渐升高，细胞重新吸水，发生质壁分离后自动复原。

第5章 细胞的能量供应和利用

把呼吸和光合画成两张流程图

这是必修1的最大分值区。先背场所和产物，再练曲线，最后做光合—呼吸综合题。只背文字不画图，很容易在“场所”和“物质去向”上丢分。

A+级 选择、曲线、实验 20-25分

必背骨架

  • 酶是活细胞产生的具有催化作用的有机物，大多数是蛋白质，少数是RNA；作用机理是降低化学反应的活化能。
  • 酶具有高效性、专一性、作用条件较温和；低温抑制活性，高温、过酸、过碱使酶变性失活。
  • ATP是细胞生命活动的直接能源物质，结构简式A-P~P~P；ATP与ADP相互转化，ATP水解释放能量。
  • 有氧呼吸：第一阶段细胞质基质，葡萄糖→丙酮酸+[H]+少量ATP；第二阶段线粒体基质，丙酮酸+H2O→CO2+[H]+少量ATP；第三阶段线粒体内膜，[H]+O2→H2O+大量ATP。
  • 无氧呼吸：细胞质基质；葡萄糖→2丙酮酸→2酒精+2CO2（酵母菌、植物）或2乳酸（动物、乳酸菌）；释放少量能量。
  • 光合作用：光反应在类囊体薄膜，水光解产生O2、NADPH和ATP；暗反应在叶绿体基质，CO2固定形成C3，C3还原形成糖类。
  • 光合作用释放的O2来自水，不是CO2；光反应为暗反应提供ATP和NADPH，暗反应为光反应提供ADP、Pi和NADP+。
  • 叶绿体色素：叶绿素a、叶绿素b主要吸收红光和蓝紫光；胡萝卜素、叶黄素主要吸收蓝紫光。
  • 总反应式：有氧呼吸 C6H12O6+6O2+6H2O→6CO2+12H2O+能量；光合作用 6CO2+12H2O→C6H12O6+6O2+6H2O。
  • 净光合速率＝总光合速率－呼吸速率；光补偿点时净光合为0，光饱和点后限制因素可能是CO2浓度或温度。

高频题型

酶的高效性、专一性、温度/pH影响实验。ATP结构与ATP/ADP相互转化。有氧呼吸三阶段：场所、反应物、产物、能量。无氧呼吸两条路径：酒精发酵与乳酸发酵。光合作用光反应与暗反应的场所、物质变化、能量变化。光照强度、CO2浓度、温度对光合速率的影响曲线。温度、O2浓度、CO2浓度和水分对细胞呼吸的影响；低温、低氧、干燥利于种子储藏。光合—呼吸综合：净光合速率、补偿点、饱和点。

有氧呼吸三阶段

阶段场所关键产物
一细胞质基质丙酮酸、[H]、少量ATP
二线粒体基质CO2、[H]、少量ATP
三线粒体内膜H2O、大量ATP

光合作用两阶段

阶段场所关键物质
光反应类囊体薄膜O2、NADPH、ATP
暗反应叶绿体基质C3、C5、糖类

易错点

  • 有氧呼吸第二阶段产生CO2，第三阶段消耗O2并产生水。
  • 无氧呼吸第二阶段不产生ATP，ATP只在第一阶段产生。
  • 光反应产生的O2来自水的光解，不是CO2。
  • 突然停止光照，C3增加、C5减少；突然停止CO2供应，C3减少、C5增加。
  • 酶变性失活是空间结构破坏，肽键不一定断裂；低温抑制不等于变性。

必刷题

先做，再看解析
选择酶的作用机理是
  1. 提供能量
  2. 降低化学反应的活化能
  3. 改变反应产物
  4. 增加反应物浓度

答案：B

解析：酶通过降低化学反应的活化能来加快反应速率，不提供能量，也不改变反应产物。

选择有氧呼吸第二阶段产生CO2的场所是
  1. 细胞质基质
  2. 线粒体基质
  3. 线粒体内膜
  4. 细胞膜

答案：B

解析：有氧呼吸第二阶段在线粒体基质中进行，丙酮酸和水反应生成CO2和[H]。

选择光合作用光反应为暗反应提供的物质是
  1. O2和ATP
  2. ATP和NADPH
  3. CO2和NADPH
  4. C3和ATP

答案：B

解析：光反应产生的ATP和NADPH用于暗反应中C3的还原。

选择突然停止光照，短时间内叶绿体中C3和C5含量的变化是
  1. C3增加、C5减少
  2. C3减少、C5增加
  3. 都增加
  4. 都减少

答案：A

解析：停止光照后，ATP和NADPH减少，C3还原受阻，C3积累；C5 regeneration减少，因此C5减少。

第6章 细胞的生命历程

用一条时间轴记住分裂、分化、衰老和死亡

这一章内容多，但考题很固定：细胞周期、有丝分裂各期、染色体/DNA数目、分化与凋亡。先抓图像，再背结论。

B+级 识图、选择 10-15分

必背骨架

  • 细胞周期：连续分裂的细胞，从一次分裂完成时开始，到下一次分裂完成时为止；间期在前，分裂期在后；间期时间最长。
  • 细胞不能无限长大：细胞体积越大，相对表面积越小，物质运输效率越低；细胞核的控制范围也有限。
  • 间期完成DNA复制和有关蛋白质合成；DNA数目加倍，染色体数目不变。
  • 有丝分裂：前期核膜核仁消失、染色质变成染色体、纺锤体形成；中期染色体着丝粒排列在赤道板上，形态最清晰；后期着丝粒分裂，姐妹染色单体分开，染色体数目暂时加倍；末期核膜核仁重建、细胞质分裂。
  • 动物细胞有中心体，末期细胞膜内陷；植物细胞有细胞壁，末期形成细胞板。
  • 细胞分化：基因的选择性表达，使细胞形态、结构和功能发生稳定性差异；一般不可逆。
  • 细胞凋亡：由基因决定的细胞程序性死亡；细胞坏死是病理性的被动死亡。
  • 癌细胞：无限增殖、形态结构改变、细胞膜表面糖蛋白减少、黏着性降低、易扩散转移。

高频题型

细胞周期判断：只有连续分裂的细胞才有细胞周期。有丝分裂各期图像识别：前期、中期、后期、末期。染色体、DNA、染色单体数目变化。细胞分化的实质：基因选择性表达。细胞凋亡与细胞坏死的区别。癌细胞特征与致癌因素。

数目变化口诀：间期DNA加倍，染色体不加倍；后期着丝粒分裂，染色体加倍，DNA不加倍；末期细胞一分为二，数目回到起点。

易错点

  • 间期DNA复制后，DNA数目加倍，但染色体数目不变。
  • 着丝粒分裂发生在后期，染色体数目暂时加倍，DNA数目不变。
  • 细胞分化过程中遗传物质一般不变，变化的是基因表达。
  • 细胞凋亡是主动的、由基因控制的；细胞坏死是被动的、病理性的。
  • 植物细胞有丝分裂末期形成细胞板，不是细胞膜内陷。

必刷题

先做，再看解析
选择有丝分裂过程中，染色体数目暂时加倍发生在
  1. 间期
  2. 前期
  3. 中期
  4. 后期

答案：D

解析：后期着丝粒分裂，姐妹染色单体分开成为两条染色体，染色体数目暂时加倍。

选择细胞凋亡是指
  1. 细胞意外死亡
  2. 由基因决定的程序性死亡
  3. 细胞衰老
  4. 细胞癌变

答案：B

解析：细胞凋亡是由基因决定的细胞程序性死亡，对生物体正常发育和维持内部稳定有积极意义。

选择观察根尖分生组织细胞有丝分裂时，解离的目的是
  1. 使组织细胞相互分离
  2. 使染色体着色
  3. 使细胞保持生活状态
  4. 使DNA复制

答案：A

解析：解离液（盐酸和酒精）可使组织中的细胞相互分离，便于制片和观察。

06 · GRAPHS

曲线题：先看起点，再看趋势，最后找限制因素

生物曲线题不要求你画得很漂亮，要求你能说清楚：横纵坐标是什么、拐点意味着什么、平台期受什么限制。

酶活性—温度

低温抑制，高温变性；最适温度两侧活性下降。

光合速率—光照强度

光补偿点之前净光合为负，之后上升，达到光饱和点后趋于平台。

呼吸速率—O2浓度

低氧时无氧呼吸较强，随O2升高有氧呼吸增强，总呼吸曲线先降后升。

有丝分裂 DNA与染色体

间期DNA加倍；后期染色体加倍；末期细胞分裂后回到起点。

曲线题四步：①写横纵坐标含义；②描述起点和趋势；③指出拐点/平台；④解释限制因素。不会时先写“随……增大，……先……后……”，就能拿到大部分描述分。
