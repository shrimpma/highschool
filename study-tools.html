02把抽象画出来：三个关键跃升

高一理科最难的不是计算，是三个“看不见”的东西：函数的对应关系、矢量的方向、微观粒子的数量。拖动下面的参数，先让图象和数字替你说话，再回到题目。

数学 · 二次函数：一个式子，五种信息

拖动 a / h / k

抽象在哪：从“算出一个数”变成“研究一个关系”。同一个式子同时给出开口、对称轴、最值、单调区间——先学会从图上读出来，再学会从式子上看出来。

y = 0.8(x − 1.0)² − 2.0

a 决定开口方向和胖瘦，h 决定左右平移，k 决定上下平移。把 a 拖到 0 附近，看它退化成什么。

物理 · 矢量合成：夹角越大，合力越小

拖动夹角 θ

抽象在哪：力不只是大小，还有方向。两个 3 N 的力，合起来可能是 6 N，也可能是 3 N 甚至 0 N——先看清这一点，受力分析才不会把力当数字加减。

60°

公式：F合 = √(F₁² + F₂² + 2F₁F₂cosθ)。这里 F₁ = F₂ = 3 N，所以 F合 = 6cos(θ/2)。θ = 120° 时合力正好 3 N。

化学 · 物质的量：连接宏观与微观的桥

输入质量自动换算

抽象在哪：看不见的粒子，和天平上的克数，被 n 连起来。不要背三个公式，只记一个中心 n 和三座桥；换算时先问“我现在在哪一端”。

三座桥：n = m / M（质量 ↔ 物质的量）、n = N / NA（粒子数 ↔ 物质的量）、n = V / Vm（气体体积 ↔ 物质的量）。
常数：NA = 6.02×10²³ mol⁻¹；标准状况下 Vm = 22.4 L/mol。

1 mol 任何物质都含 6.02×10²³ 个粒子。36 g 水是 2 mol，所以有 1.20×10²⁴ 个水分子。

看完不等于会用：关掉这一节，拿一道同类题，先画图 / 先写三座桥，再动笔算。卡住的地方，就是下一个要补的断点。

03卡点急救：5 分钟规则

放弃不是一次决定，是一条循环：听不懂 → 抄过去 → 假装会 → 考试崩 → 不敢投入。打断这条循环只需要一个动作：卡住时不超过 5 分钟，画个“？”，继续往下。把卡点写成一句具体的话，第二天或周末集中处理。

05:00

卡住先计时，5 分钟到就画“？”，继续往下。

把“我不会”写成一句能问出口的话

为什么要把卡点写清楚：“这题不会”没人能帮；“作差之后不知道往哪变形”一句话就能被点通。问得越具体，越不丢人；憋着不问，才会真的掉队。

04每天 20 分钟：最小任务与连续天数

分数有延迟，但“今天完成了几个动作”是即时反馈。每天只做三件事：回滚 5 分钟 → 理解着记 10 分钟 → 白纸复现 5 分钟。选一科，做完打勾，先求连续，再求时长。

今天完成 0 / 3 连续记录从今天开始 进度只存在本机浏览器
为什么是 20 分钟：目标是“每天都发生”，不是“一次学很久”。20 分钟版本也能留下一张白纸；宁可每天一张，也不要一周只学一次、一次三小时。做满 3 个勾，这一天就算过关。
用 file:// 打开时：部分浏览器不会保存勾选。要保留进度，在仓库根目录起一个本地静态服务器再打开，例如 python -m http.server，然后访问 http://127.0.0.1:8000/study-tools.html。

同样一次失败，归因方式决定下一步：归到“我不行”，就会撤出投入；归到“某个断点”，就会去补。下面四句话，把前者换成后者。

问问题很丢人问得越具体，越容易被点通用上面的求助句写清“卡在哪一步”

判断进步，先看这三个指标（而不是分数）

  • 白纸上能复现的条目数，每周记一次。
  • 单个卡点的停留时间，从 30 分钟降到 5 分钟。
  • 每周主动提问次数，至少 3 次，而且问得具体。
一句话：高一的困难大多不是智力问题，而是思维换挡、进度累积、方法失效、反馈延迟同时发生。学生手里只有初中那一套工具时，“放弃”看起来像唯一选项。补上第一个断点，循环就会开始反向转。

06常见问题

三个工具要每天全做吗？

不用。断点自检每月一次；可视化在学对应章节或卡住时用；5 分钟规则随时用；每日最小任务每天做。工具是减少负担的，不是增加打卡负担的。

诊断勾了很多条，是不是要从头补？

不要。按页面顺序只补第一条，两周后再重测。很多断点是连着的，补上前面的，后面的会自己松动。一次补六个，通常一个都补不完。

为什么先做数理化，生物呢？

数理化的断点最集中、最靠前：函数影响整个数学，受力分析影响整个力学，物质的量影响整个化学计算。生物更多是记忆与过程理解，下一步会按同样的结构补上。

可视化看懂了，做题还是不会，怎么办？

“看懂”只是第一层。合上页面，拿一道同类题：先画图或先写三座桥，再动笔。卡住的地方写进求助句，那就是下一个断点。看懂之后必须有一次自己动手的复现。

勾选和进度没有保存？

这些数据写在浏览器 localStorage 里。用 file:// 直接打开时，部分浏览器会禁用；改用本地静态服务器（例如 python -m http.server）访问，或允许该站点保存数据即可。

打印出来有什么用？

打印版会展开所有断点的补法，可以当一张自查表：先不勾，隔两周再拿笔勾一次，对比两次的差别。互动图和计时器在纸上不会运行，屏幕上看即可。
