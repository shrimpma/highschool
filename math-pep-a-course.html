一、怎么用这份课件

数学靠「记结论」只能应付眼前，靠「懂来路」才能举一反三。这份课件每一节都按下面这条主线编排：

① 看懂「为什么」

先给一个直观图，再给一步不跳的推导。比如基本不等式不是背出来的，是用半圆的半径与垂线比出来的。

② 记住「是什么」

把推导收成一句口诀、一张表、一条公式，方便快速提取。配合公式块反复默写。

③ 会「怎么用」

每节配经典例题（答案折叠在「看解析」里），先自己做，再看步骤。

④ 结构化复习

每章末有「本章一张图 + 易错清单」，考前扫一眼就能过一遍。

第一章 集合与常用逻辑用语

教材 p.4–38 · 建议 4–5 天 · 以选择、填空为主
基础章 · 必须全对
本章主线 集合是一堆「确定对象」装进一个袋子；逻辑用语讲「谁能推出谁」。全章最怕符号写错、端点开闭错、否定漏结论。

1.1 集合的概念

学习目标
  • 会用列举法、描述法表示集合，会用 ∈ / ∉ 表示元素与集合的关系。
完全掌握的自测标准
  • 不看答案，能说出集合三要素并各举一例；能指出「高个子」不是集合、「身高>180cm的人」是集合。
冲击 80% 的中档自测
  • 利用互异性解含参集合：已知 {1, a}={1, a²}，求出 a 的值（得 a=0，并说明为什么 a≠1）。

定义把确定的对象放在一起，就构成一个集合。集合有三个要素：确定性、互异性、无序性。

三要素含义举例说明
确定性一个对象「在」或「不在」集合，必须能说清「高个子」不是集合（多高算高？）；「身高>180cm的人」是集合
互异性同一元素不能重复算两次{1,1,2} 只能写成 {1,2}
无序性元素顺序无关{1,2}={2,1}

元素与集合的关系用 ∈（属于）/ ∉（不属于）；集合与集合的关系用 ⊆（含于）。两者不要混。

1.2 集合间的基本关系

学习目标
  • 能判断子集、真子集、相等关系，记住空集是任何集合的子集。
完全掌握的自测标准
  • 不看答案，能默写 n 元集合的子集数 2ⁿ、真子集数 2ⁿ−1，并写出 {a,b} 的全部子集（含 ∅）。
冲击 80% 的中档自测
  • 含参包含关系：已知 A={x|0≤x≤1}、B={x|a≤x≤a+1}，若 B⊆A，求出 a 的范围（a=0）。
子集 A⊆B：A 中每个元素都在 B 中
真子集 A⊊B：A⊆B 且 A≠B
空集 ∅ 是任何集合的子集

易错一个含 n 个元素的集合，子集有 2ⁿ 个，真子集有 2ⁿ−1 个，非空真子集有 2ⁿ−2 个。别把空集 ∅ 漏算——它也算一个子集。

1.3 集合的基本运算（交、并、补）

学习目标
  • 会求交集、并集、补集，并用区间正确表示（注意端点开闭）。
完全掌握的自测标准
  • 不看答案，能算出 [1,3]∩[2,5]=[2,3]、[1,3]∪[2,5]=[1,5]，补集端点开闭不写错。
冲击 80% 的中档自测
  • 综合运算：已知 U=ℝ、A={x|−2≤x≤3}、B={x|1<x<4}，求 ∁ᵤ(A∪B)（答案 (−∞,−2)∪[4,+∞)）。
运算符号含义区间例子
交集A ∩ B既在 A 又在 B[1,3]∩[2,5]=[2,3]
并集A ∪ B在 A 或在 B（含两边）[1,3]∪[2,5]=[1,5]
补集∁ᵤA在全集 U 中、不在 AU=ℝ, A=(0,1] → ∁ᵤA=(−∞,0]∪(1,+∞)

用「画圈」来想：交集是重叠部分，并集是全部，补集是全集里去掉 A 剩下的。

1.4 充分条件与必要条件

学习目标
  • 能根据 p⇒q 判断四种条件关系，牢记「箭头前充分、箭头后必要」。
完全掌握的自测标准
  • 不看答案，能判断「x>1 是 x>0 的充分不必要条件」，并说清判断过程。
冲击 80% 的中档自测
  • 复合充要判断：已知 p: x²−1=0、q: x=1，判断 p 是 q 的什么条件（必要不充分，因 x²−1=0 得 x=±1）。

核心就一句：「p 推出 q」记作 p ⇒ q。看箭头方向就能定关系。

充分条件（p ⇒ q）

p 是 q 的充分条件
（有 p 就够了）

口诀：箭头前是「充分」，箭头后是「必要」。

必要条件（q 是 p 的必要）

p ⇒ q 时，q 是 p 的必要条件
（没 q 不行）
推导 · 四类条件怎么分
  1. 先写两个命题：p 和 q。
  2. 判断 p ⇒ q 是否成立；再判断 q ⇒ p 是否成立。
  3. 都成立 → 充要；只 p⇒q → 充分不必要；只 q⇒p → 必要不充分；都不成立 → 既不充分也不必要。

记法：把「⇒」当成一根箭头，箭头从「充分」指向「必要」。

1.5 全称量词与存在量词

学习目标
  • 会写全称 / 存在命题的否定，做到「量词换、结论反」。
完全掌握的自测标准
  • 不看答案，能写出「∀x∈R, x²≥0」的否定为「∃x∈R, x²<0」。
冲击 80% 的中档自测
  • 否定 + 真假：写出「∀x∈R, x²+x+1>0」的否定并判断真假（∃x∈R, x²+x+1≤0，为假，Δ<0）。

全称量词 ∀（所有、任意）否定后变 存在 ∃；存在量词 ∃ 否定后变 全称 ∀。易错否定时量词要换，结论也要取反。

「∀x∈M, p(x)」的否定是「∃x∈M, ¬p(x)」
「∃x∈M, p(x)」的否定是「∀x∈M, ¬p(x)」
经典例题 · 1

已知集合 A={x | x²−3x+2=0}，B={x | 0<x<5, x∈N}，求 A∩B。

看解析

先解 A：x²−3x+2=(x−1)(x−2)=0 → x=1 或 2，故 A={1,2}。B 是 0 到 5 之间的自然数，B={1,2,3,4}。所以 A∩B={1,2}。

经典例题 · 2

“x>1” 是 “x>0” 的什么条件？

看解析

x>1 ⇒ x>0 成立；但 x>0 时不一定 x>1（如 x=0.5），即 x>0 ⇏ x>1。所以是充分不必要条件。

第二章 一元二次函数、方程和不等式

教材约 p.39–61 · 建议 5–6 天 · 贯穿后续函数章
工具章 · 期中必考
本章主线 三件事：不等式性质（移项、变号）、基本不等式（求最值）、三个二次（二次函数 / 二次方程 / 二次不等式是一家）。

2.1 不等式的基本性质

学习目标
  • 掌握两边加数、乘正 / 负、平方、取倒数的规则，牢记乘负数要变号。
完全掌握的自测标准
  • 不看答案，能说出「两边同乘一个负数」时方向要变，并正确解 −2x>6 得 x<−3。
冲击 80% 的中档自测
  • 变形正误：已知 a>b，判断 ac²>bc²、a−c>b−c、1/a<1/b 哪些恒成立（只有 a−c>b−c 恒成立）。
操作等式不等式易错
两边加同一数成立成立—
两边乘正数成立方向不变—
两边乘负数成立方向要变忘变号
两边平方需讨论只有两边非负才能平方漏条件
两边取倒数一般可同号才可，且方向要变乱取倒数

2.2 基本不等式（必会）

学习目标
  • 会用 (a+b)/2 ≥ √(ab) 求最值，理解圆的几何证法，并检查等号条件。
完全掌握的自测标准
  • 不看答案，能独立求出 x>0 时 x+4/x 的最小值为 4，并写出等号在 x=2 时成立。
冲击 80% 的中档自测
  • 配凑求最值：已知 x>−1，求 x+1/(x+1) 的最小值（凑 (x+1)+1/(x+1)−1，得最小 1，x=0 取等）。
若 a>0, b>0，则 (a+b)/2 ≥ √(ab)，当且仅当 a=b 时取等号。
推导 · 基本不等式从哪来（圆 + 半径 + 垂线，不用死记）
  1. 画一个半圆，直径 AB = a + b；在直径上取一点 C，使 AC = a、CB = b。
  2. 过 C 作直径 AB 的垂线，交半圆于 D。因为直径所对的圆周角 ∠ADB = 90°，所以 △ACD 与 △DCB 相似。
  3. 由相似得 AC : CD = CD : CB，即 CD² = AC · CB = a·b，于是 高 CD = √(ab)。
  4. 半圆的半径 OD = (a+b)/2（圆心 O 是直径中点）。
  5. 半径 OD 是斜线，高 CD 是垂线段；从同一点 D 出发，斜线总是不短于垂线，所以 OD ≥ CD。
  6. 代入即得 (a+b)/2 ≥ √(ab)；当且仅当 C 与圆心 O 重合（即 a=b）时取等号。

左边是半圆的半径（算术平均），右边是半圆内的高（几何平均）。「半径 ≥ 垂线」一句话记住整个不等式。

几何意义：半径 (a+b)/2 是「斜线」，半圆内的高 √(ab) 是「垂线」，斜线总不短于垂线；当 C 移到圆心 O（a=b）时两者相等。

✗ 最值题最容易丢的 2 分 用基本不等式求最值，务必检查两件事：① a、b 是否为正；② 等号能否取到（a=b 是否成立）。少写「当且仅当 a=b」会扣分。

2.3 三个二次（二次函数 · 方程 · 不等式）

学习目标
  • 会用图象法解二次不等式，牢记「大于取两边，小于取中间」。
完全掌握的自测标准
  • 不看答案，能解 x²−3x−4>0，正确写出解集 (−∞,−1)∪(4,+∞)。
冲击 80% 的中档自测
  • 恒成立：已知 x²−ax+4>0 对一切 x∈R 恒成立，求 a 的范围（Δ<0 得 −4<a<4）。

必会二次函数 y=ax²+bx+c 的图象是一条抛物线；令 y=0 得到二次方程 ax²+bx+c=0；令 y>0 或 y<0 得到二次不等式。三者是同一个抛物线的不同问法。

开口向上时：大于取两边，小于取中间。这是解二次不等式的万能口诀。

推导 · 解二次不等式的标准步骤
  1. 移项，把不等式化为 ax²+bx+c □ 0（□ 是 >、≥、<、≤）。
  2. 最好让二次项系数 a>0（若 a<0，两边同乘 −1，不等号方向要变）。
  3. 算判别式 Δ = b²−4ac，判断图象与 x 轴交点个数。
  4. 求根（因式分解、配方或求根公式）。
  5. 结合图象写解集：开口向上时「大于取两边，小于取中间」。
经典例题 · 3

解不等式 x² − 3x − 4 > 0。

看解析

因式分解：(x−4)(x+1)>0。两根 x=−1、x=4。开口向上，大于取两边：解集为 (−∞,−1)∪(4,+∞)。

经典例题 · 4

已知 x>0，求 x + 4/x 的最小值。

看解析

x>0 且 4/x>0，可用基本不等式：x + 4/x ≥ 2√(x·4/x) = 2√4 = 4。等号当且仅当 x = 4/x，即 x=2 时成立。故最小值为 4。

第三章 函数的概念与性质

教材约 p.62–105 · 建议 7–8 天 · 高中数学主线起点
核心章 · 重中之重
本章主线 函数是「输入一个 x，按规则输出唯一一个 y」。本章学定义域、值域、单调性、奇偶性，是第 4、5 章的基础。

3.1 函数的概念（三要素）

学习目标
  • 理解函数三要素（定义域、对应关系、值域），会求简单函数的定义域。
完全掌握的自测标准
  • 不看答案，能求 f(x)=√(x−1)/(x−2) 的定义域，分母、根号两个条件都不漏。
冲击 80% 的中档自测
  • 复合定义域：已知 f(x) 的定义域为 [0,2]，求 f(2x−1) 的定义域（1/2≤x≤3/2）。

三要素

  • 定义域：自变量 x 的取值集合（先求！）
  • 对应关系 f：怎么把 x 变成 y
  • 值域：所有 y 组成的集合

两个函数相等 ⇔

定义域相同 且 对应关系相同

值域相同不能说明函数相等（常见陷阱）。

结构限制条件例子
分母≠ 0f(x)=1/(x−2) → x≠2
偶次根式被开方数 ≥ 0f(x)=√(x−1) → x≥1
对数真数 > 0（且底 a>0,a≠1）f(x)=log₂(x−3) → x>3
实际问题符合实际意义人数是正整数

3.2 函数的基本性质（单调性与奇偶性）

学习目标
  • 会用「作差法」五步证明单调性；会用 f(−x) 判断奇偶性，先查定义域对称。
完全掌握的自测标准
  • 不看答案，能完整写出作差法五步证明一个函数单调，并判断 f(x)=x³+x 为奇函数。
冲击 80% 的中档自测
  • 抽象综合：已知偶函数 f(x) 在 [0,+∞) 上递减，比较 f(−1)、f(2)、f(3) 的大小（f(−1)=f(1)>f(2)>f(3)）。
性质定义图象特征证明方法
增函数x₁<x₂ ⇒ f(x₁)<f(x₂)从左到右上升作差法
减函数x₁<x₂ ⇒ f(x₁)>f(x₂)从左到右下降作差法
奇函数f(−x)=−f(x)，定义域关于原点对称关于原点对称算 f(−x)
偶函数f(−x)=f(x)，定义域关于原点对称关于 y 轴对称算 f(−x)
推导 · 用定义证明 f(x)=x²+2x 在 (0,+∞) 上单调递增（作差法模板）
  1. 设 0 < x₁ < x₂（在给定区间内任取两个 x）。
  2. 作差：f(x₁) − f(x₂) = (x₁²+2x₁) − (x₂²+2x₂)。
  3. 因式分解：= (x₁−x₂)(x₁+x₂+2)。
  4. 判号：因为 x₁<x₂，所以 x₁−x₂<0；又 x₁,x₂>0，故 x₁+x₂+2>0。所以 f(x₁)−f(x₂)<0，即 f(x₁)<f(x₂)。
  5. 结论：f(x) 在 (0,+∞) 上单调递增。

这套「设—作差—变形—判号—结论」五步，是解答题拿过程分的标准写法。

3.3 幂函数 y=x^α

学习目标
  • 记住 y=x、x²、x³、√x、1/x 的图象、定义域、奇偶性与单调性，都过 (1,1)。
完全掌握的自测标准
  • 不看答案，能默写这五个幂函数的定义域、奇偶性和在 (0,+∞) 上的单调性。
冲击 80% 的中档自测
  • 反求参数：已知幂函数 f(x)=x^α 过点 (2,1/4)，求 α 及单调性（α=−2，在 (0,+∞) 递减）。

必会幂函数都过定点 (1,1)。先画第一象限，再用奇偶性补另一半。

函数定义域奇偶性在(0,+∞)上的单调性
y=xℝ奇增
y=x²ℝ偶增
y=x³ℝ奇增
y=x^(1/2)=√x[0,+∞)非奇非偶增
y=x^(−1)=1/x{x|x≠0}奇减

α 越大，第一象限越陡；α 为负时（如 y=1/x）图象两支在两条坐标轴之间。

经典例题 · 5

求函数 f(x) = √(4−x²) / (x−1) 的定义域。

看解析

两个限制：① 偶次根号下 4−x²≥0 → x²≤4 → −2≤x≤2；② 分母 x−1≠0 → x≠1。两者取交集：定义域为 [−2,1)∪(1,2]。

经典例题 · 6

判断 f(x) = x³ + x 的奇偶性。

看解析

定义域 ℝ 关于原点对称。f(−x)=(−x)³+(−x)=−x³−x=−(x³+x)=−f(x)。所以 f(x) 是奇函数。

第四章 指数函数与对数函数

教材约 p.106–169 · 建议 8–10 天 · 提分主战场
高分段 · 题型固定
本章主线 「指数」和「对数」是一对互逆运算（像加减、乘除那样）。重点记互化、图象、运算法则三件事。

4.1 指数与指数幂

学习目标
  • 理解分数指数幂 a^(m/n)=ⁿ√(aᵐ)，会用指数运算法则化简。
完全掌握的自测标准
  • 不看答案，能化简 a^(1/2)·a^(1/3)=a^(5/6)，并说清负指数表示倒数。
冲击 80% 的中档自测
  • 化简为幂：把 (√a · a^(3/2)) / a 化成一个幂（a^(1/2+3/2−1)=a）。
推导 · 分数指数幂怎么来
  1. n 次方根：若 xⁿ=a，则 x 叫做 a 的 n 次方根，记作 ⁿ√a。
  2. 规定：a^(m/n) = ⁿ√(aᵐ)（a>0，m、n 为正整数）。
  3. 规定：a^(−n) = 1/aⁿ（负指数表示倒数）。
  4. 这样，整数指数幂的运算律对分数指数幂同样成立。
aᵐ · aⁿ = aᵐ⁺ⁿ　｜　aᵐ / aⁿ = aᵐ⁻ⁿ　｜　(aᵐ)ⁿ = aᵐⁿ　｜　(ab)ⁿ = aⁿbⁿ

4.3 对数与对数运算

学习目标
  • 掌握 aᵇ=N ⇔ logₐN=b 的互化，会三条运算性质与换底公式。
完全掌握的自测标准

冲击 80% 的中档自测
  • 换底求值：已知 lg2≈0.3010、lg3≈0.4771，求 log₂3（=lg3/lg2≈1.585）。
推导 · 对数定义（互化是关键）
  1. 若 aᵇ = N（a>0, a≠1, N>0），则把 b 记作 b = logₐ N。
  2. 于是「指数式」和「对数式」可以互相改写：aᵇ = N ⇔ logₐ N = b。
  3. 由定义立得两条恒等式：logₐ(aᵏ) = k；a^(logₐ N) = N。

对数的运算性质

logₐ(MN) = logₐM + logₐN
logₐ(M/N) = logₐM − logₐN
logₐ(Mᵏ) = k·logₐM

换底公式

logₐb = log_c b / log_c a
（常用 c=10 或 c=e）

用途：把不同底的对数化成同底，方便比大小、化简。

4.5 函数的零点与二分法

学习目标
  • 理解零点存在定理（f(a)f(b)<0 ⇒ 有零点），会二分法三步。
完全掌握的自测标准
  • 不看答案，能说清「至少有一个零点」≠「只有」，并写出二分法三步。
冲击 80% 的中档自测
  • 零点存在定理：证明方程 x³+x−1=0 在 (0,1) 内有零点（f(0)=−1<0, f(1)=1>0）。

零点存在定理

f 在 [a,b] 上连续，且 f(a)·f(b)<0 ⇒ (a,b) 内至少有一个零点。

易错「至少」不是「恰好」；条件不满足时，不能断定没有零点。

二分法步骤

  1. 取中点 x₀=(a+b)/2
  2. 看 f(x₀) 的符号，缩小区间
  3. 重复，直到区间长度小于精度
经典例题 · 7

化简：log₂8 + log₂(1/4)。

看解析

log₂8 = log₂(2³) = 3；log₂(1/4)=log₂(2⁻²)=−2。所以 3 + (−2) = 1。

经典例题 · 8

比较 log₂3 与 log₃2 的大小。

看解析

log₂3 > log₂2 = 1；log₃2 < log₃3 = 1。所以 log₂3 > 1 > log₃2，即 log₂3 > log₃2。关键技巧：拿 1 当中间量。

5.1 任意角与弧度制

学习目标

推导 · 弧度制怎么来
  1. 规定：弧长等于半径的弧，所对的圆心角是 1 弧度（1 rad）。
  2. 于是弧长 l、半径 r、圆心角 α 满足 l = |α|·r（α 用弧度表示）。

  4. 于是 π rad = 180°。换算：1° = π/180 rad；1 rad = 180°/π ≈ 57.3°。

5.2 三角函数的概念

学习目标
  • 用单位圆理解 sinα=y、cosα=x、tanα=y/x，掌握 sin²α+cos²α=1 与 tanα=sinα/cosα。
完全掌握的自测标准
  • 不看答案，能由 sinα=3/5 且 α 在第二象限，求出 cosα=−4/5、tanα=−3/4。
冲击 80% 的中档自测
  • 符号判断：已知 sinθ·cosθ<0，判断 θ 所在象限（第二或第四象限）。

在单位圆（半径 1）上取角 α 的终边与圆交于点 P(x,y)，则定义：

sinα = y（纵坐标）　cosα = x（横坐标）　tanα = y/x
推导 · 同角基本关系（直接从勾股定理来）
  1. 点 P(x,y) 在单位圆上，满足 x² + y² = 1。
  2. 把 x=cosα、y=sinα 代入，得 sin²α + cos²α = 1。
  3. 两边同除以 cos²α，得 tan²α + 1 = 1/cos²α（即 1+tan²α=sec²α）。

这条公式不是背的，是单位圆上「勾股定理」换了个说法。

5.5 三角恒等变换

学习目标
  • 会用两角和差与二倍角公式，理解 cos(α−β) 是源头。
完全掌握的自测标准
  • 不看答案，能默写 sin2α、cos2α 的三种形式，并说明它们都从 cos(α−β) 推出。
冲击 80% 的中档自测
  • 弦化切：已知 tanα=2，求 (sinα+cosα)/(sinα−cosα)（分子分母同除 cosα 得 3）。
两角和差：sin(α±β)=sinαcosβ±cosαsinβ；cos(α±β)=cosαcosβ∓sinαsinβ
二倍角：sin2α=2sinαcosα；cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α
推导 · cos(α−β) 的来路（和差角公式的源头）
  1. 在单位圆上取两个角 α、β，对应点 P(cosα,sinα)、Q(cosβ,sinβ)。
  2. 用两点间距离公式算 |PQ|²，再与旋转后算出的同一段弧长距离相等。
  3. 化简即得 cos(α−β)=cosαcosβ+sinαsinβ。
  4. 把 β 换成 −β，得 cos(α+β)；再用「sinθ=cos(π/2−θ)」推出 sin 的和差公式；令 α=β 即得二倍角公式。

所有三角恒等式，源头都在这一个 cos(α−β) 上——记住它的来历，整章公式就串起来了。
